What counts as a bug here

On this page

  • Something that used to work and no longer does
  • A page, download or certificate that will not load
  • Content that renders wrongly, or not at all, on a common device
  • Anything that blocks a screen reader or keyboard user
  • A factual error in course material

Tracked elsewhere

  • Service outages — on System Status, which is about whether the site is up rather than whether a feature is correct
  • Feature requests — on Updates & Roadmap and in the tracker under enhancement
  • Security reports — please do not open a public issue; write to us via Contact so we can fix it before it is public
