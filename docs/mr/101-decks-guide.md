# 101 कोर्स डेक मार्गदर्शक

## 101 कोर्स डेक म्हणजे काय?

ImpactMojo चे **80 पायाभूत अभ्यासक्रम** दृश्य सादरीकरण डेक स्वरूपात उपलब्ध आहेत — [Gamma](https://gamma.app) द्वारे तयार केलेले 60-स्लाइड परस्परसंवादी डेक, ज्यात भारतीय लोककलेची चित्रे, सुसंगत ब्रँडिंग आणि सर्वत्र दक्षिण आशियाई संदर्भ आहे.

हे नेहमीचे स्लाइड डेक नाहीत. प्रत्येक एक स्वयं-अध्ययनासाठी किंवा सुलभीकृत कार्यशाळांसाठी रचलेला संरचित शिक्षण प्रवास आहे, ज्यात भारत आणि दक्षिण आशियातील विकास पद्धतीतून घेतलेले केस स्टडी आहेत. हे पाहणे, शेअर करणे आणि शैक्षणिक संदर्भात वापरणे विनामूल्य आहे.

सर्व डेक `https://www.impactmojo.in/101-courses/{course-slug}.html` येथे उपलब्ध आहेत आणि कोणत्याही लॉगिन किंवा डाउनलोडची आवश्यकता नाही.

**नवीन नेटिव्ह डेकसाठी कार्यप्रवाह:**
1. विद्यमान नेटिव्ह डेकला स्वरूप टेम्पलेट म्हणून वापरून Claude Chat मध्ये 100-स्लाइड HTML तयार करा
2. आउटपुट `101-courses/{slug}.html` येथे जतन करा/पेस्ट करा
3. JS बग दुरुस्त करा (स्लाइड 50 नंतर व्ह्यूपोर्ट विभाजन, चार्ट लेबलमधील नवीन ओळी) आणि पुश करा

उर्वरित 35 डेक अजूनही Gamma iframe रॅपर वापरतात आणि टप्प्याटप्प्याने स्थलांतरित केले जातील.

## प्रत्येक डेकमध्ये काय आहे

प्रत्येक 101 डेक अंदाजे 60–100 स्लाइडमध्ये एक सुसंगत रचना अनुसरतो:

1. **शीर्षक कार्ड** — अभ्यासक्रमाचे नाव, ImpactMojo ब्रँडिंग, ट्रॅक ओळख
2. **कार्यसूची** — डेक काय समाविष्ट करतो याचे विहंगावलोकन
3. **10--12 आशय विभाग** — स्पष्टीकरणे, आकृत्या आणि दक्षिण आशियाई केस स्टडीसह मूळ संकल्पना
4. **प्रश्नमंजुषा / मूल्यांकन** — डेकमध्ये अंतर्भूत तुमची-समज-तपासा प्रश्न
5. **मुख्य मुद्दे** — सर्वात महत्त्वाच्या मुद्द्यांचा सारांश
6. **शब्दकोश** — डेकमध्ये वापरलेल्या मुख्य संज्ञांच्या व्याख्या
7. **अधिक वाचन** — सखोल अन्वेषणासाठी निवडक संदर्भ
8. **धन्यवाद** — परवाना आणि श्रेयासह समारोप स्लाइड

### ब्रँडिंग आणि डिझाइन

- **फॉन्ट**: Inter (मजकूर) + Amaranth (शीर्षके)
- **थीम**: Cornflower (सर्व डेकमध्ये सुसंगत)
- **तळटीप**: प्रत्येक स्लाइडवर ImpactMojo ब्रँडिंग
- **परवाना**: CC BY-NC-ND 4.0 — श्रेयासह अव्यावसायिक वापरासाठी शेअर आणि रूपांतर करणे विनामूल्य

## शिक्षकांसाठी

### कार्यशाळांमध्ये डेक वापरणे

60-स्लाइड स्वरूप **90-मिनिटांच्या कार्यशाळा सत्राशी** चांगले जुळते:

1. **परिचय** (10 मिनिटे) — सत्र मांडण्यासाठी शीर्षक कार्ड आणि कार्यसूची स्लाइड वापरा
2. **आशय फेरफटका** (50 मिनिटे) — आशय विभागांमधून काम करा, केस स्टडीवर गट चर्चेसाठी विराम घ्या
3. **प्रश्नमंजुषा आणि चर्चा** (15 मिनिटे) — अंतर्भूत प्रश्नमंजुषा गट क्रियाकलाप म्हणून वापरा
4. **मुख्य मुद्दे आणि चिंतन** (15 मिनिटे) — मुख्य मुद्द्यांचा आढावा घ्या, सहभागींना ते लागू करतील अशी एक संकल्पना ओळखण्यास सांगा

### हँडआउटसह संयोजन

ImpactMojo `/Handouts/` मध्ये 84 हँडआउट प्रदान करते जे डेकशी चांगले जुळतात. उदाहरणार्थ:

- पूर्ण-दिवस कार्यशाळेसाठी **Data Literacy डेक** Data & Technology ट्रॅकच्या हँडआउटसह वापरा
- डेक सादर करण्यापूर्वी पूर्व-वाचन म्हणून **MEL Fundamentals हँडआउट** वितरित करा

### गेमसह संयोजन

अनेक 101 अभ्यासक्रमांसाठी प्लॅटफॉर्मवर सोबती परस्परसंवादी गेम आहेत:

- **Development Economics** डेक + **Public Good Game** किंवा **Externality Game**
- **Digital Development Ethics** डेक + **Digital Ethics** परिस्थिती
- **Climate Essentials** डेक + **Climate Action Challenge**
- **Political Economy** डेक + **Cooperation Paradox** किंवा **Prisoners' Dilemma**

प्रथम गेम खेळून अनुभवात्मक आकर्षण तयार करा, नंतर संकल्पनात्मक चौकट उभारण्यासाठी डेक वापरा.

### स्थानिक संदर्भासाठी सानुकूलन

डेक CC BY-NC-ND 4.0 परवानाधारक आहेत, याचा अर्थ तुम्ही करू शकता:

- **रूपांतर** — स्थानिक केस स्टडी जोडा, मुख्य संज्ञा अनुवादित करा, तुमच्या राज्यासाठी किंवा प्रदेशासाठी उदाहरणे समायोजित करा

## तांत्रिक तपशील

### डेक कसे तयार केले जातात

डेक स्वयंचलित पाइपलाइनद्वारे **Gamma API** वापरून प्रोग्रामॅटिकपणे तयार केले जातात:

1. **अभ्यासक्रम आशय** विभाग शीर्षके, केस स्टडी आणि मूल्यांकन घटकांसह एका प्रॉम्प्टमध्ये संरचित केला जातो
2. **Gamma API** cornflower थीम आणि निर्दिष्ट कला शैलीसह 60-स्लाइड डेक तयार करते
3. यशस्वी निर्मितीनंतर **PDF निर्यात** आपोआप चालना मिळते
4. **सिंक परिणाम** ट्रॅकिंगसाठी `data/gamma-sync-results.json` मध्ये नोंदवले जातात

### सिंक पाइपलाइन

- **स्क्रिप्ट**: `scripts/gamma-sync.js` संपूर्ण निर्मिती आणि निर्यात कार्यप्रवाह हाताळते
- **पुनर्प्राप्ती**: पाइपलाइन पुनर्प्राप्तीला समर्थन देते — जर निर्मिती यशस्वी झाली परंतु PDF निर्यात अयशस्वी झाली (उदा. क्रेडिट मर्यादांमुळे), तर Gamma URL जतन केला जातो आणि निर्यात नंतर पुन्हा करता येते
- **स्थिती ट्रॅकिंग**: प्रत्येक अभ्यासक्रमाची `gamma-sync-results.json` मध्ये एक स्थिती असते: `completed` (निर्यात URL सह किंवा त्याशिवाय) किंवा `error` (निर्मिती अद्याप प्रयत्न केलेली नाही/अयशस्वी)

### सध्याची पाइपलाइन स्थिती

- **18 डेक**: PDF निर्यातासह पूर्णपणे पूर्ण

## टिपा

- **सादर करण्यापूर्वी पूर्वावलोकन करा.** कार्यशाळेत वापरण्यापूर्वी स्वतः एक डेक पाहा. कोणते केस स्टडी तुमच्या प्रेक्षकांशी जुळतात आणि कोणत्या स्लाइड तुम्ही वगळू शकता किंवा विस्तृत करू शकता ते लक्षात घ्या.
- **शब्दकोश वापरा.** विकास परिभाषा लोकांना गोंधळात टाकते. नवीन संज्ञा सादर करताना सहभागींना शब्दकोश स्लाइडकडे निर्देशित करा.
- **केस स्टडीमध्ये घाई करू नका.** दक्षिण आशियाई केस स्टडीमध्येच अमूर्त संकल्पना ठोस होतात. ते उदाहरण त्यांच्या स्वतःच्या कामाशी कसे जोडले जाते यावर चर्चा करण्यासाठी सहभागींना वेळ द्या.
- **फील्ड सेटिंगसाठी PDF डाउनलोड करा.** जर तुम्ही अविश्वसनीय इंटरनेट असलेल्या भागात कार्यशाळा चालवत असाल, तर आधीच PDF डाउनलोड करा. थेट कनेक्शनशिवाय लॅपटॉपवरून प्रोजेक्ट केल्यावर डेक चांगले कार्य करतात.
- **एकाच ट्रॅकमधील डेक जोडा.** बहु-दिवसीय प्रशिक्षण चालवत आहात? संचयी शिक्षणासाठी एकाच ट्रॅकमधील दोन किंवा तीन डेक क्रमवार लावा — उदाहरणार्थ, Data Literacy नंतर Bivariate Analysis नंतर Multivariate Analysis.
