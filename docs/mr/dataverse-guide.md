# Dataverse मार्गदर्शक

## Dataverse म्हणजे काय?

ImpactMojo Dataverse हा 16 श्रेणींमध्ये आयोजित **343 डेटा स्रोत, साधने आणि सेवांचा निवडक संग्रह** आहे — विशेषतः दक्षिण आशिया आणि त्यापलीकडे काम करणाऱ्या विकास संशोधक आणि प्रॅक्टिशनर्ससाठी डिझाइन केलेला.

विकास कामासाठी जगातील सर्वात उपयुक्त डेटाचा नकाशा म्हणून याचा विचार करा, अशा प्रकारे आयोजित केलेला की तुम्हाला जे हवे आहे ते प्रत्यक्षात सापडेल. योग्य dataset किंवा साधन शोधण्यात तास घालवण्याऐवजी, Dataverse पडताळलेली, संबंधित संसाधने तुमच्या बोटांच्या टोकावर ठेवते.

Dataverse मधील प्रत्येक नोंदीचे संबंधितता, प्रवेशयोग्यता आणि गुणवत्तेसाठी पुनरावलोकन केले गेले आहे. आम्ही अशा संसाधनांना प्राधान्य देतो जी विनामूल्य आहेत किंवा ज्यांना विनामूल्य स्तर आहेत, जी दक्षिण आशियाई संदर्भ समाविष्ट करतात, आणि जी डेटा शास्त्रज्ञ नसलेल्या लोकांनाही वापरता येतात.

## संसाधन प्रकार समजून घेणे

Dataverse मध्ये सात प्रकारची संसाधने आहेत. यापैकी काही संज्ञा तुमच्यासाठी नवीन असल्यास, काळजी करू नका — प्रत्येकाचा अर्थ काय आहे आणि तुम्ही ते कधी वापराल हे येथे आहे.

### 1. Dataset

**dataset** म्हणजे डेटाचा डाउनलोड करण्यायोग्य संग्रह — संख्या, सर्वेक्षण प्रतिसाद, निर्देशक, मोजमापे — ओळी आणि स्तंभांमध्ये आयोजित केलेला. जर तुम्ही कधी संख्यांनी भरलेल्या spreadsheet सोबत काम केले असेल, तर तुम्ही dataset सोबत काम केले आहे.

**तुम्ही हे कधी वापराल:** तुम्ही एक प्रस्ताव लिहित आहात आणि तीन जिल्ह्यांसाठी गरिबीची आकडेवारी हवी आहे. तुम्ही एखाद्या कार्यक्रमाच्या आधी आणि नंतरचे आरोग्य परिणाम विश्लेषण करत आहात. तुम्ही राज्यांमधील शिक्षण निर्देशकांची तुलना करत आहात.

**उदाहरण:** भारताचा राष्ट्रीय कुटुंब आरोग्य सर्वेक्षण (NFHS) डेटा — आरोग्य, पोषण आणि लोकसंख्याशास्त्रावरील कुटुंब-स्तरीय डेटा जो तुम्ही डाउनलोड आणि विश्लेषण करू शकता.

### 2. Tool

**tool** म्हणजे असे सॉफ्टवेअर जे तुम्ही वापरू शकता — तुमच्या वेब ब्राउझरमध्ये किंवा तुमच्या संगणकावर इन्स्टॉल केलेले — डेटासह *काहीतरी करण्यासाठी*. एक chart तयार करा. एक सर्वेक्षण तयार करा. एक गोंधळलेली spreadsheet स्वच्छ करा. मुलाखतींमधील मजकूर विश्लेषण करा.

**तुम्ही हे कधी वापराल:** तुम्हाला अहवालासाठी एक graph बनवायचा आहे. तुम्हाला baseline मूल्यमापनासाठी एक ऑनलाइन सर्वेक्षण तयार करायचे आहे. तुम्ही PDF तक्ता वापरण्यायोग्य spreadsheet मध्ये रूपांतरित करण्याचा प्रयत्न करत आहात.

**उदाहरण:** Datawrapper — कोणताही कोड न जाणता स्पष्ट, व्यावसायिक charts तयार करण्यासाठी ब्राउझर-आधारित साधन.

### 3. Platform

**platform** म्हणजे एक वेबसाइट किंवा ऑनलाइन सेवा जिथे तुम्ही डेटा किंवा संसाधने शोधू, एक्सप्लोर करू आणि डाउनलोड करू शकता. याचा विचार ग्रंथालयासारखा करा, पण ऑनलाइन — तुम्हाला जे हवे ते ब्राउझ करण्यासाठी आणि शोधण्यासाठी तुम्ही तिथे जाता.

**तुम्ही हे कधी वापराल:** तुम्ही एका विशिष्ट विषयावर डेटा शोधत आहात पण नेमके काय उपलब्ध आहे याची खात्री नाही. लिंग समानता मोजण्यासाठी कोणते निर्देशक अस्तित्वात आहेत हे एक्सप्लोर करू इच्छिता. तुम्हाला एका विशिष्ट देश किंवा प्रदेशातील डेटा शोधायचा आहे.

**उदाहरण:** World Bank Open Data — एक platform जिथे तुम्ही जगातील जवळजवळ प्रत्येक देशासाठी विकास निर्देशक शोधू आणि डाउनलोड करू शकता.

### 4. API (Application Programming Interface)

**API** म्हणजे संगणक प्रोग्रामना विशिष्ट डेटाची स्वयंचलितपणे विनंती करण्याचा एक मार्ग. वेबसाइटवर जाऊन "download" क्लिक करण्याऐवजी, API तुम्हाला म्हणू देते, "मला गेल्या 10 वर्षांचा भारताचा GDP द्या" — आणि सेवा नेमका तोच डेटा परत पाठवते.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** जर तुम्हाला नियमितपणे डेटा खेचावा लागत असेल (मासिक अहवाल, त्रैमासिक पुनरावलोकने), किंवा तुम्हाला एकाच वेळी अनेक देशांचा डेटा हवा असेल, तर मॅन्युअल डाउनलोडच्या तुलनेत API प्रचंड वेळ वाचवते.

**बहुतेक API वापरण्यासाठी तुम्ही प्रोग्रामर असण्याची गरज नाही.** अनेकांमध्ये साधे वेब इंटरफेस असतात जिथे तुम्ही जे हवे ते निवडता आणि परिणाम मिळवता. आणि जर तुम्ही ImpactMojo च्या डेटा अभ्यासक्रमांद्वारे काम करत असाल, तर तुम्ही टप्प्याटप्प्याने API वापरायला शिकाल.

**उदाहरण:** World Bank API तुम्हाला विशिष्ट देश आणि वर्षांसाठी विशिष्ट निर्देशकांची विनंती करू देते — जेव्हा तुम्हाला नेमका तोच डेटा हवा असतो, त्यापेक्षा अधिक काही नाही, तेव्हा उपयुक्त.

### 5. MCP Server (Model Context Protocol)

**MCP Server** म्हणजे AI सहाय्यकांना (जसे Claude) थेट थेट डेटा स्रोतांशी जोडण्याचा एक मार्ग. तुम्ही मॅन्युअली डेटा शोधून डाउनलोड करण्याऐवजी, तुम्ही तुमच्या AI सहाय्यकाला सांगू शकता, "मला भारताचा नवीनतम GDP डेटा आणून दे," आणि तो MCP कनेक्शनद्वारे माहिती आणतो.

**असा विचार करा:** कल्पना करा की तुम्ही तुमच्या संशोधन सहाय्यकाला एका विशिष्ट डेटाबेसचे ग्रंथालय कार्ड देत आहात. तुम्हाला स्वतः ग्रंथालयात जाण्याची गरज न पडता ते आता तुमच्यासाठी गोष्टी शोधू शकतात. MCP Server एका AI सहाय्यकासाठी हेच करतो.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** संशोधनात AI साधने अधिक सामान्य होत असताना, गुंतागुंतीच्या डेटा पोर्टलमधून मार्गक्रमण करण्याऐवजी नैसर्गिक संभाषणाद्वारे विश्वसनीय, अधिकृत डेटा अॅक्सेस करण्यास MCP Servers तुम्हाला परवानगी देतात. तुम्ही साध्या भाषेत प्रश्न विचारता, आणि AI जोडलेल्या स्रोतातून अचूक डेटा आणतो.

**उदाहरण:** भारताच्या data.gov.in शी जोडलेला MCP Server तुम्हाला AI सहाय्यकाकडून नवीनतम कृषी उत्पादन आकडेवारी मागून प्रत्यक्ष डेटा परत मिळवू देऊ शकतो — केवळ AI चे सामान्य ज्ञान नाही.

### 6. Resource

**resource** म्हणजे संदर्भ साहित्य जे तुम्हाला डेटा समजून घेण्यास आणि त्यासह काम करण्यास मदत करते — पद्धतीशास्त्रीय मार्गदर्शक, frameworks, manuals आणि निवडक संग्रह. हे डेटा स्वतः नाही, तर डेटा *बद्दलचे* ज्ञान आहे.

**तुम्ही हे कधी वापराल:** तुम्हाला कार्यक्रम प्रभाव मोजण्याचा सर्वोत्तम दृष्टिकोन समजून घ्यायचा आहे. तुम्हाला नैतिक डेटा संकलनाचे मार्गदर्शक हवे आहे. तुम्ही तुमच्या मूल्यमापन डिझाइनसाठी एक framework शोधत आहात.

**उदाहरण:** 3ie Evidence Gap Map पद्धती मार्गदर्शक — एक resource जे विकास विषयावर कोणते संशोधन अस्तित्वात आहे (आणि नाही) हे पद्धतशीरपणे नकाशावर कसे आणायचे हे स्पष्ट करते.

### 7. Skill (Claude Skill)

**Skill** म्हणजे Claude AI सहाय्यकासाठी एक पूर्व-निर्मित कमांड जी एक विशिष्ट संशोधन किंवा विश्लेषण कार्य करते. एका पाककृतीसारखी: तुम्ही skill ला आमंत्रित करता (एक कमांड टाइप करून), आणि काहीतरी साध्य करण्यास तुम्हाला मदत करण्यासाठी ती चरणांचा संरचित क्रम चालवते.

**तुम्ही हे कधी वापराल:** तुम्हाला एखाद्या विकास कार्यक्रमाचे विश्लेषण करायचे आहे पण कुठून सुरुवात करावी याची खात्री नाही. तुम्हाला पद्धतशीरपणे साहित्याचे पुनरावलोकन करायचे आहे. तुम्हाला एका विशिष्ट हस्तक्षेपासाठी मूल्यमापन प्रश्न तयार करायचे आहेत.

**उदाहरण:** "/analyze-program" सारखी एक skill तुम्हाला एखाद्या विकास हस्तक्षेपाच्या संरचित मूल्यमापनातून मार्गदर्शन करू शकते — तुम्हाला योग्य प्रश्न विचारणे, संबंधित डेटा खेचणे, आणि तुमचे निष्कर्ष आयोजित करण्यास मदत करणे.

## 16 श्रेणी

Dataverse आपली 343 संसाधने 16 श्रेणींमध्ये आयोजित करते. प्रत्येकात काय आहे आणि ते कोणासाठी सर्वात उपयुक्त आहे ते येथे आहे.

### 1. India Government Data

भारतीय सरकारी संस्थांचे अधिकृत डेटा पोर्टल — data.gov.in, NITI Aayog dashboards, जनगणना डेटा, मंत्रालय-स्तरीय डेटाबेस आणि राज्य डेटा पोर्टल. तुम्ही भारतातील कार्यक्रमांवर काम करत असाल आणि अधिकृत आकडेवारीची गरज असल्यास **येथून सुरुवात करा**.

### 2. Global Development Data

World Bank, संयुक्त राष्ट्र संस्था, SDG trackers आणि बहुपक्षीय संस्थांकडून आंतरराष्ट्रीय विकास डेटा. तुम्हाला देशांमध्ये तुलना करायची असेल, जागतिक उद्दिष्टे ट्रॅक करायची असतील, किंवा आंतरराष्ट्रीय benchmarks उद्धृत करायचे असल्यास **येथून सुरुवात करा**.

### 3. Health & Epidemiology

WHO, Demographic and Health Surveys (DHS) कार्यक्रम, रोग पाळत यंत्रणा, पोषण डेटाबेस आणि आरोग्य सुविधा रजिस्ट्रींकडून आरोग्य डेटा. तुम्ही सार्वजनिक आरोग्य, WASH, पोषण किंवा आरोग्य प्रणालींमध्ये काम करत असल्यास **येथून सुरुवात करा**.

### 4. Education & Learning

UNESCO, ASER Centre, शिक्षण परिणाम डेटाबेस, शाळा पायाभूत सुविधा डेटा आणि साक्षरता सर्वेक्षणांकडून शिक्षण डेटा. तुम्ही शिक्षण, कौशल्य विकास किंवा युवा कार्यक्रमांमध्ये काम करत असल्यास **येथून सुरुवात करा**.

### 5. Economic & Financial

Reserve Bank of India, IMF, व्यापार आकडेवारी डेटाबेस, आर्थिक समावेशन निर्देशक आणि कुटुंब उपभोग सर्वेक्षणांकडून आर्थिक डेटा. तुम्ही उपजीविका, बाजार प्रणाली, आर्थिक समावेशन किंवा आर्थिक धोरणावर काम करत असल्यास **येथून सुरुवात करा**.

### 6. Research & Evidence

संशोधन repositories आणि पुरावा डेटाबेस — JSTOR, 3ie evidence gap maps, Cochrane systematic reviews आणि शैक्षणिक शोध साधने. तुम्ही मूल्यमापन डिझाइन करत असाल, साहित्य पुनरावलोकन लिहित असाल, किंवा काय कार्य करते याचा पुरावा शोधत असल्यास **येथून सुरुवात करा**.

### 7. Data Visualization

charts, नकाशे, dashboards आणि दृश्य कथा तयार करण्यासाठी साधने — Datawrapper, Flourish, chart-निर्मिती templates आणि visualization मार्गदर्शक. अहवाल, सादरीकरणे किंवा प्रकाशनांमध्ये डेटा स्पष्टपणे संप्रेषित करायचा असल्यास **येथून सुरुवात करा**.

### 8. M&E & Impact

देखरेख, मूल्यमापन आणि शिक्षण साधने — MEAL frameworks, मूल्यमापन डेटाबेस, परिणाम framework templates आणि Behaviour Change Technique (BCT) repository. तुम्ही M&E प्रणाली उभारत असाल, मूल्यमापन डिझाइन करत असाल, किंवा परिणाम framework तयार करत असल्यास **येथून सुरुवात करा**.

### 9. Geospatial & Mapping

GIS साधने, प्रशासकीय सीमा फाइल्स, उपग्रह प्रतिमा संसाधने आणि mapping platforms. प्रस्तावांसाठी नकाशे हवे असतील, कार्यक्रमाचे भौगोलिक कव्हरेज visualize करायचे असेल, किंवा स्थान-आधारित डेटासह काम करत असल्यास **येथून सुरुवात करा**.

### 10. Climate & Environment

### Dataverse चा जास्तीत जास्त फायदा मिळवण्यासाठी टिपा

- **तुम्ही नियमितपणे वापरता ती संसाधने bookmark करा.** तुमचे आवडते जतन करण्यासाठी एक विनामूल्य ImpactMojo खाते तयार करा.
- **संसाधन प्रकार एकत्र करा.** एक सामान्य संशोधन workflow डेटा शोधण्यासाठी एक Platform, ते visualize करण्यासाठी एक Tool, आणि तुमच्या पद्धतीशास्त्राचे मार्गदर्शन करण्यासाठी एक Resource वापरू शकतो.
- **डेटाची तारीख आणि कव्हरेज तपासा.** प्रत्येक dataset प्रत्येक राज्य किंवा प्रत्येक वर्ष समाविष्ट करत नाही. तुमचे विश्लेषण त्याभोवती तयार करण्यापूर्वी काय समाविष्ट आहे ते नेहमी तपासा.
- **सोप्यापासून सुरुवात करा.** जर तुम्ही कधीही API वापरले नसेल, तर point-and-click इंटरफेस असलेल्या Platform पासून सुरुवात करा. तुमची सोय वाढत असताना तुम्ही API आणि MCP Servers कडे प्रगती करू शकता.
- **तुमच्या टीमसोबत शेअर करा.** Dataverse विनामूल्य आहे — फायदा होऊ शकणाऱ्या सहकाऱ्यांसोबत विशिष्ट संसाधन लिंक शेअर करा.
