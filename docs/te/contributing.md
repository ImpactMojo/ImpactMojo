# ImpactMojo కు సహకరించడం

సహకరించడంలో మీ ఆసక్తికి ధన్యవాదాలు! ImpactMojo అభివృద్ధి సమాజం చేత మరియు దాని కోసం నిర్మించబడింది. మీరు కాలం చెల్లిన గణాంకాన్ని గుర్తించిన అభ్యాసకుడైనా, గొప్ప కేస్ స్టడీ ఉన్న ఉపాధ్యాయుడైనా, లేదా బగ్‌ను సరిచేయగల డెవలపర్ అయినా — మీరు సహకరించడానికి ఒక అర్థవంతమైన మార్గం ఉంది.

## మీరు సాంకేతికంగా ఉండాల్సిన అవసరం లేదు

మా అత్యంత విలువైన సహకారాలలో చాలా వరకు ప్రోగ్రామర్ల నుండి కాదు, అభ్యాసకుల నుండి వస్తాయి. ఒక్క కోడ్ లైన్ కూడా రాయకుండా మీరు ఎలా సహాయపడవచ్చో ఇక్కడ ఉంది:

| మీరు ఏమి చేయవచ్చు | ఎలా | కష్టం |
|-----------------|-----|------------|
| **లోపాన్ని నివేదించండి** | విరిగిన లింక్, తప్పు గణాంకం, లేదా కాలం చెల్లిన సూచనను కనుగొన్నారా? ఒక [Content Issue](https://github.com/ImpactMojo/ImpactMojo/issues/new?template=content_issue.md) తెరవండి | చాలా సులభం |
| **ఒక అంశాన్ని సూచించండి** | కవర్ చేయాల్సిన అంశం తెలుసా? ఒక [Discussion](https://github.com/ImpactMojo/ImpactMojo/discussions/categories/ideas) ప్రారంభించండి | చాలా సులభం |
| **ఒక కేస్ స్టడీని పంచుకోండి** | మీ పని నుండి వాస్తవ-ప్రపంచ అభివృద్ధి కేస్ స్టడీ ఉందా? hello@impactmojo.in వద్ద మాకు ఇమెయిల్ చేయండి | సులభం |
| **కంటెంట్‌ను అనువదించండి** | హిందీ, తమిళం, బెంగాలీ, తెలుగు, లేదా మరాఠీలో కోర్సులను అందుబాటులో ఉంచడంలో సహాయపడండి | సులభం–మధ్యస్థం |
| **కంటెంట్‌ను సమీక్షించండి** | మీరు MEL, జెండర్ అధ్యయనాలు, లేదా అభివృద్ధి ఆర్థికశాస్త్రంలో నిపుణులా? ఖచ్చితత్వం కోసం కోర్సులను సమీక్షించడంలో మాకు సహాయపడండి | సులభం |
| **ఒక హ్యాండ్‌అవుట్ రాయండి** | మీకు బాగా తెలిసిన అంశంపై ఒక సూచన షీట్‌ను సృష్టించండి | మధ్యస్థం |

## సాంకేతిక సహకారుల కోసం

మీకు HTML, CSS, లేదా JavaScript తో సౌకర్యం ఉంటే, సహకరించడానికి చాలా మార్గాలు ఉన్నాయి:

| ప్రాంతం | ఉదాహరణలు | కష్టం |
|------|----------|------------|
| **బగ్ ఫిక్స్‌లు** | విరిగిన లింక్‌లు, లేఅవుట్ సమస్యలు, JavaScript లోపాలు | సులభం–మధ్యస్థం |
| **ప్రాప్యత** | WCAG సమ్మతి, స్క్రీన్ రీడర్ మద్దతు, కీబోర్డ్ నావిగేషన్ | మధ్యస్థం |
| **డిజైన్** | UI/UX మెరుగుదలలు, మొబైల్ అనుభవం | మధ్యస్థం |
| **సాధనాలు & ల్యాబ్‌లు** | ఇంటరాక్టివ్ అభ్యాస సాధనాలను నిర్మించండి లేదా మెరుగుపరచండి | కష్టం |
| **గేమ్‌లు** | కొత్త ఆర్థికశాస్త్ర సిమ్యులేషన్లు | మధ్యస్థం–కష్టం |

### ప్రారంభం (సాంకేతిక)

ImpactMojo ఒక వానిలా HTML/CSS/JS ప్రాజెక్ట్ — చట్రాలు లేవు, బిల్డ్ దశ లేదు. మీరు కేవలం ఒక వెబ్ బ్రౌజర్ మరియు ఒక సరళమైన సర్వర్‌తో దీన్ని స్థానికంగా నడపవచ్చు:

```bash
# 1. Fork and clone the repository
git clone https://github.com/<your-username>/ImpactMojo.git
cd ImpactMojo

# 2. Start a local server (pick whichever you have)
python -m http.server 8000
# or: npx http-server -p 8080

# 3. Open http://localhost:8000 in your browser

# 4. Create a branch for your changes
git checkout -b feature/your-feature-name

# 5. Make your changes, test locally

# 6. Commit using the prefix convention
git commit -m "Add: descriptive summary of what you did"

# 7. Push and open a Pull Request on GitHub
git push origin feature/your-feature-name
```

### కమిట్ సందేశ నియమం

ప్రతి కమిట్ సందేశం మార్పు రకాన్ని వివరించే ఉపసర్గతో ప్రారంభమవుతుంది:

| ఉపసర్గ | ఎప్పుడు ఉపయోగించాలి | ఉదాహరణ |
|--------|---------------|---------|
| `Add:` | కొత్త ఫీచర్, కోర్సు, లేదా సాధనం | `Add: interactive budget planning lab` |
| `Fix:` | బగ్ ఫిక్స్ లేదా విరిగిన లింక్ | `Fix: broken nav dropdown on mobile Safari` |
| `Update:` | ఉన్న కంటెంట్ లేదా కోడ్‌కు మెరుగుదల | `Update: MEL course module 3 with 2025 data` |
| `Translate:` | అనువాద పని | `Translate: gender studies course to Hindi` |
| `Docs:` | డాక్యుమెంటేషన్ మార్పులు | `Docs: add workshop facilitation guide` |
| `Refactor:` | కోడ్ పునర్నిర్మాణం (ప్రవర్తన మార్పు లేదు) | `Refactor: extract auth logic to separate file` |
| `Test:` | పరీక్షలను జోడించడం లేదా నవీకరించడం | `Test: add accessibility checks for games` |
| `CI:` | CI/CD పైప్‌లైన్ మార్పులు | `CI: add broken link checker workflow` |
| `Chore:` | నిర్వహణ (డిపెండెన్సీలు, కాన్ఫిగ్‌లు) | `Chore: update dependabot config` |

### Pull Request మార్గదర్శకాలు

- PRలను కేంద్రీకృతంగా ఉంచండి — ఒక్కో PR కు ఒక ఫీచర్ లేదా ఫిక్స్
- డెస్క్‌టాప్ మరియు మొబైల్‌లో పరీక్షించండి
- దృశ్య మార్పుల కోసం స్క్రీన్‌షాట్‌లను చేర్చండి
- మార్పులు ప్రీమియం ఫీచర్లను ప్రభావితం చేస్తే గమనించండి

## కంటెంట్ రచన శైలి

మీరు విద్యా కంటెంట్‌కు సహకరిస్తుంటే, మేము దేని కోసం లక్ష్యంగా పెట్టుకుంటామో ఇక్కడ ఉంది:

- **స్వరం:** అందుబాటులో ఉండేది కానీ కఠినమైనది. 2–3 సంవత్సరాల అనుభవం ఉన్న అభ్యాసకుడి కోసం రాయండి.
- **ఉదాహరణలు:** దక్షిణాసియా సందర్భాన్ని (భారతదేశం, బంగ్లాదేశ్, నేపాల్, శ్రీలంక) ప్రాధాన్యత ఇవ్వండి.
- **పరిభాష:** మొదటి ఉపయోగంలో పదాలను నిర్వచించండి. ఇది సాధారణ రంగ పదమైతే, దాన్ని [ImpactLex](https://www.impactmojo.in/impactlex/) కు జోడించండి.
- **ఆపాదన:** ఎల్లప్పుడూ మూలాలను ఉదహరించండి. వీలైతే [DevDiscourses](https://www.impactmojo.in/dataverse) కు లింక్ చేయండి.
- **ప్రాప్యత:** స్పష్టమైన శీర్షికలు, చిత్రాలకు alt text, మరియు తగినంత రంగు కాంట్రాస్ట్‌ను ఉపయోగించండి.

## సమస్యలను నివేదించడం

తగిన టెంప్లేట్‌తో [GitHub Issues](https://github.com/ImpactMojo/ImpactMojo/issues) ను ఉపయోగించండి:

- **Bug Report** — ఏదో విరిగింది (లింక్, లేఅవుట్, లోపం)
- **Feature Request** — ఒక కొత్త ఆలోచన లేదా మెరుగుదల
- **Content Issue** — వాస్తవిక లోపం, కాలం చెల్లిన సమాచారం, తప్పిపోయిన అంశం
