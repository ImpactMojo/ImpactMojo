# ImpactLex வழிகாட்டி

## ImpactLex என்றால் என்ன?

ImpactLex என்பது ImpactMojo-வின் **வளர்ச்சிக் கலைச்சொற்களின் தேடக்கூடிய சொற்களஞ்சியம்** — வளர்ச்சித் துறை வல்லுநர்கள் தினமும் சந்திக்கும் சுருக்கச்சொற்கள் (acronyms), கருத்துருக்கள், சூத்திரங்கள், கட்டமைப்புகள், வழக்கு ஆய்வுகள் மற்றும் நிறுவனங்கள்.

இது [impactmojo.in/impactlex](https://www.impactmojo.in/impactlex/) என்ற முகவரியில் இருக்கிறது, இணையமில்லாமல் பயன்படுத்த ஒரு Progressive Web App (PWA) ஆக நிறுவப்படுகிறது, மேலும் ImpactMojo-வின் 21 முதன்மைப் பாடநெறி சொற்களஞ்சியங்களின் அதே சொல்-தொகுப்பிலிருந்து உள்ளடக்கத்தை எடுக்கிறது — எனவே MEL பாடநெறியில் நீங்கள் கற்பது, அந்தச் சொல் தோன்றும் எந்த இடத்திலும் ஒரே மாதிரியாகத் தோன்றுகிறது.

**அணுகல்:** இலவசம் — [ImpactLex-ஐத் திறக்கவும்](https://www.impactmojo.in/impactlex/)

## ImpactLex எதை உள்ளடக்கியது

| வகை | எடுத்துக்காட்டுகள் |
|----------|----------|
| **சுருக்கச்சொற்கள்** | DALY, WASH, NREGA, SDG, GBV, FGD, KII, ToC, MEL, BCC |
| **கருத்துருக்கள்** | எதிர்மறைத் தேர்வு (adverse selection), நெறிமுறை இடர் (moral hazard), இடைவெட்டுத்தன்மை (intersectionality), பரேட்டோ திறன், சமூக மூலதனம் |
| **சூத்திரங்கள்** | கினி குணகம், செலவு-விளைதிறன் விகிதம், சராசரி சிகிச்சை விளைவு (Average Treatment Effect), HDI |
| **கட்டமைப்புகள்** | Theory of Change, Logical Framework, முடிவு-அடிப்படை மேலாண்மை, GESI பகுப்பாய்வு |
| **முறைகள்** | RCT, வேறுபாட்டில்-வேறுபாடு (difference-in-differences), சாய்வுமதிப்பு பொருத்தம், மிக முக்கியமான மாற்றம் |
| **நிறுவனங்கள்** | World Bank, UNDP, 3ie, J-PAL, NITI Aayog, NSSO, Grameen, BRAC |
| **வழக்கு ஆய்வுகள்** | Progresa, Graduation Approach, PROGRESA, BRAC, ஜனனி சுரக்ஷா யோஜனா |

ஒவ்வொரு பதிவும் கல்வியாளர்களுக்காக அல்ல, மாறாக செயற்பாட்டாளர்களுக்காக எழுதப்பட்டுள்ளது. வரையறைகள் ஒரு சொல்லின் பொருளை மட்டுமல்ல, அதை எப்போது, ஏன் பயன்படுத்துவீர்கள் என்பதையும் விளக்குகின்றன. எடுத்துக்காட்டுகள் இயல்பாகவே தெற்காசியாவை அடிப்படையாகக் கொண்டவை.

## அம்சங்கள்

- சொற்கள், சுருக்கச்சொற்கள், மாற்றுப்பெயர்கள், வரையறைகள் முழுவதும் **உடனடித் தேடல்**
- **வகை வடிகட்டிகள்** — சுருக்கச்சொல், கருத்துரு, சூத்திரம், கட்டமைப்பு, முறை அல்லது நிறுவனம் வாரியாக உலாவவும்
- **பாடநெறி வடிகட்டிகள்** — MEL, Gender, DataViz, DevAI, DevEcon, Gandhi, Law, PoA, PubPol அல்லது SEL-இல் பயன்படுத்தப்படும் சொற்களை மட்டும் பார்க்கவும்
- **நாளின் சொல் (Term of the Day)** — காலப்போக்கில் சொற்களஞ்சியத்தைக் கட்டியெழுப்ப மாறிமாறிவரும் சிறப்புச் சொல்
- **குறுக்குக் குறிப்புகள்** — மீண்டும் தேடாமல் ஒரு தொடர்புடைய சொல்லுக்குத் தாவ கிளிக் செய்யவும்
- **புத்தகக்குறிகள்** — உங்கள் உலாவியில் பிடித்தவற்றைச் சேமிக்கவும்; உள்நுழையும்போது உங்கள் கணக்குடன் ஒத்திசைக்கப்படும்
- **இணையமில்லா அணுகல்** — களப் பயன்பாட்டிற்காக இணையமில்லாமல் மொபைலில் PWA ஆக நிறுவவும்
- **ஆழ்-இணைக்கக்கூடிய சொற்கள்** — ஒவ்வொரு சொல்லுக்கும் அதன் சொந்த URL உள்ளது (`/impactlex/term.html?id=theory-of-change`), பகிரக்கூடியது மற்றும் தேடலில் அட்டவணைப்படுத்தப்பட்டது
- **சமூகப் பங்களிப்புகள்** — புதிய சொற்கள் அல்லது திருத்தங்களைப் பரிந்துரைக்கவும்; வெளியிடுவதற்கு முன் மதிப்பாய்வு செய்யப்படும்

## ImpactLex-ஐப் பயன்படுத்துதல்

### ஒரு பட்டறைக் குறிப்பாக

அமர்வுகளின்போது ImpactLex-ஐ திரையிடுங்கள், இதனால் பங்கேற்பாளர்கள் அறிமுகமில்லாத சொற்களை நிகழ்நேரத்தில் தேடிப் பார்க்க முடியும். வளர்ச்சித் துறை வழக்குச்சொற்கள் ஒரு உண்மையான தடை — ஒரு தேடக்கூடிய குறிப்பு இருப்பது "அதன் அர்த்தம் என்ன என்று கேட்க விரும்பவில்லை" என்ற பிரச்சினையைக் குறைக்கிறது.

### ஒரு படிப்பு உதவியாக

ஒவ்வொரு வாரமும் 5–10 புதிய சொற்களைக் கற்கச் சொல்லுங்கள். சூழல்சார் வரையறைகள், பாடப்புத்தகங்களுடன் மட்டுமல்ல, அவர்களின் உண்மையான வேலையுடன் இணைக்கும் சொற்களஞ்சியத்தைக் கட்டியெழுப்ப அவர்களுக்கு உதவுகின்றன.

### பாடநெறிகளுடன் சேர்த்து

ImpactMojo-வின் ஒவ்வொரு முதன்மைப் பாடநெறிக்கும் அதன் சொந்த ஊடாடும் சொற்களஞ்சியம் உள்ளது. ImpactLex என்பது குறுக்குவெட்டுப் பார்வை — அதே சொல்-தொகுப்பு, நீங்கள் விரும்பும்போது பாடநெறி வாரியாக வடிகட்டப்பட்டது, விரும்பாதபோது ஒருங்கிணைக்கப்பட்டது. நீங்கள் MEL படிக்கிறீர்கள் என்றால், பாடநெறி சொற்களஞ்சியத்தைப் பயன்படுத்துங்கள் அல்லது ImpactLex-ஐ `MEL`-க்கு வடிகட்டுங்கள். MEL + Gender + Public Policy ஆகியவற்றை உள்ளடக்கிய ஒரு முன்மொழிவை நீங்கள் எழுதுகிறீர்கள் என்றால், ImpactLex-ஐ நேரடியாகப் பயன்படுத்துங்கள்.

### அறிக்கை எழுதுவதற்கு

பங்கேற்பாளர்கள் முன்மொழிவுகள் அல்லது அறிக்கைகளை எழுதும்போது, சொற்களைச் சரியாகப் பயன்படுத்த ImpactLex அவர்களுக்கு உதவுகிறது. "output" எதிராக "outcome" அல்லது "monitoring" எதிராக "evaluation" போன்ற சொற்களைத் தவறாகப் பயன்படுத்துவது பொதுவானது — ImpactLex செயற்பாட்டாளர் சூழலுடன் தெளிவான வரையறைகளை வழங்குகிறது.

## பங்களித்தல்

ஒரு சொல் விடுபட்டிருக்கிறதா? சரிசெய்யப்பட வேண்டிய ஒரு வரையறையைக் கண்டீர்களா? எந்த ImpactLex பக்கத்திலும் **Suggest a term** என்பதைக் கிளிக் செய்யவும். சமர்ப்பிப்புகள் மட்டுறுத்தல் வரிசைக்குச் சென்று, மதிப்பாய்வுக்குப் பிறகு தோன்றும்.

நாங்கள் குறிப்பாக வரவேற்கிறோம்:
- வேறெங்கும் இல்லாத தெற்காசியத் திட்டங்கள், நிறுவனங்கள் மற்றும் சுருக்கச்சொற்கள்
- நன்கொடையாளர் மொழி களயதார்த்தத்திலிருந்து வேறுபடும் செயற்பாட்டாளர்-குறிக்கப்பட்ட வழக்குகள்
- செய்துகாட்டப்பட்ட எடுத்துக்காட்டுகளுடன் கூடிய சூத்திரங்கள்
- மறுக்கப்படும் சொற்கள் — "resilience" அல்லது "empowerment" வெவ்வேறு நன்கொடையாளர்களுக்கு வெவ்வேறு பொருள்களைக் கொண்டிருந்தால், அதை விளக்க விரும்புகிறோம்

## திரைக்குப் பின்னால்

ImpactLex என்பது ImpactMojo-வுடன் Netlify-இல் ஓம்புசெய்யப்படும் ஒரு நிலையான (static) Progressive Web App. சொல்லகராதி என்பது களஞ்சியத்தில் உள்ள ஒரு ஸ்னாப்ஷாட் JSON கோப்பு; எனவே இந்த ஆப் இணையமில்லாமலும் செயல்படுகிறது. வாசகர்களின் பரிந்துரைகள் Supabase-இல் சேமிக்கப்பட்டு, ஒரு நிர்வாகியால் மதிப்பாய்வு செய்யப்படுகின்றன. உள்ளடக்கம் AI உதவியுடன் (Gemini/Grok/DeepSeek) வரையப்பட்டு, வெளியிடுவதற்கு முன் ஒரு மனித ஆசிரியரால் மதிப்பாய்வு செய்யப்படுகிறது.

## குறிப்புகள்

- இணையமில்லா அணுகலுக்கு **PWA-ஐ நிறுவுங்கள்** — குறிப்பாக களப் பணியாளர்களுக்குப் பயனுள்ளது.
- **குறிப்பிட்ட சொற்களை ஆழ்-இணைக்கவும்** — ஒவ்வொரு பதிவுக்கும் பகிரக்கூடிய URL உள்ளது, WhatsApp மூலம் அனுப்புவதற்கும் பட்டறைக் கையேடுகளுக்கும் நல்லது.
- **வடிகட்டிகளை இணைக்கவும்** — எ.கா., மதிப்பீட்டு முறைகளில் மட்டும் கவனம் செலுத்த "category: method" + "course: MEL".
- **ஒரு சொல்லைக் காண முடியவில்லையா?** அதைச் சமர்ப்பியுங்கள். இந்த சொற்களஞ்சியம் மேசை ஆய்விலிருந்து அல்ல, செயற்பாட்டாளர் பயன்பாட்டிலிருந்து வளர்கிறது.
