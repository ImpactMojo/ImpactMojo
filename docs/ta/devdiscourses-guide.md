# Development Discourses வழிகாட்டி

## Development Discourses என்றால் என்ன?

Development Discourses (DevDiscourses) என்பது ImpactMojo-வின் வளர்ச்சி, சமூகத் தாக்கம் மற்றும் பொதுக் கொள்கை குறித்த **500+ ஆராய்ச்சிக் கட்டுரைகள், புத்தகங்கள் மற்றும் சாம்பல் இலக்கியத்தின் (grey literature) தொகுக்கப்பட்ட திறந்த-அணுகல் தொகுப்பு** ஆகும்.

Google Scholar (மாறுபட்ட தரத்துடன் ஆயிரக்கணக்கான முடிவுகளைத் திருப்பித் தருகிறது) போலல்லாமல், DevDiscourses என்பது ஒவ்வொரு வளமும் தொடர்புடைமை, அணுகல்தன்மை மற்றும் தரத்திற்காகத் தேர்ந்தெடுக்கப்பட்ட ஒரு கையால் தொகுக்கப்பட்ட தொகுப்பு. இது **திறந்த-அணுகல் வளங்களுக்கு** முன்னுரிமை அளிக்கிறது — எனவே நீங்கள் கண்டறிவதை நீங்கள் உண்மையில் படிக்க முடியும்.

**அணுகல்:** இலவசம் — [DevDiscourses-ஐ உலாவவும்](https://on-web.link/DevDiscourses)

## DevDiscourses எதை உள்ளடக்கியது

| தலைப்புப் பகுதி | எடுத்துக்காட்டுகள் |
|-----------|---------|
| **MEL மற்றும் ஆராய்ச்சி** | மதிப்பீட்டு முறைகள், குறிகாட்டி வடிவமைப்பு, தகவமைப்பு மேலாண்மை, பங்கேற்பு ஆராய்ச்சி |
| **பாலினம் மற்றும் சமத்துவம்** | பாலின முதன்மைப்படுத்தல், இடைவெட்டுத்தன்மை, பெண்ணிய ஆராய்ச்சி முறைகள், GBV தடுப்பு |
| **காலநிலை மற்றும் சுற்றுச்சூழல்** | காலநிலைத் தகவமைப்பு, சுற்றுச்சூழல் நீதி, மீள்திறன் கட்டமைப்புகள், பேரிடர் இடர் |
| **தரவு மற்றும் ஆட்சி** | தரவு நெறிமுறைகள், படிமுறை நியாயத்தன்மை, டிஜிட்டல் வளர்ச்சி, திறந்த தரவு |
| **பொது சுகாதாரம்** | தாய்வழி சுகாதாரம், ஊட்டச்சத்து, WASH, சுகாதார அமைப்பு வலுப்படுத்தல் |
| **வாழ்வாதாரம்** | நிதி உள்ளடக்கம், சந்தை அமைப்புகள், சமூகப் பாதுகாப்பு, உழைப்புச் சந்தைகள் |
| **கொள்கை மற்றும் பொருளியல்** | வளர்ச்சிப் பொருளியல், அரசியல் பொருளியல், செலவு-விளைதிறன், பொது நிதி |

வளங்கள் **தலைப்பு, வகை, ஆசிரியர் மற்றும் முக்கியச்சொல்** வாரியாகத் தேடக்கூடியவை.

## வளங்களின் வகைகள்

- **இதழ் கட்டுரைகள்** — வளர்ச்சி மற்றும் சமூக அறிவியல் இதழ்களிலிருந்து சக-மதிப்பாய்வு செய்யப்பட்ட (peer-reviewed) ஆராய்ச்சி
- **புத்தகங்கள் மற்றும் புத்தக அத்தியாயங்கள்** — அடிப்படை நூல்கள் மற்றும் சமீபத்திய வெளியீடுகள்
- **பணிக் கட்டுரைகள் (Working papers)** — சிந்தனைக் குழுக்கள் மற்றும் ஆராய்ச்சி நிறுவனங்களிலிருந்து வெளியீட்டுக்கு-முந்தைய ஆராய்ச்சி
- **சாம்பல் இலக்கியம் (Grey literature)** — NGO-க்கள் மற்றும் பல்தரப்பு அமைப்புகளிலிருந்து திட்ட மதிப்பீடுகள், கொள்கைச் சுருக்கங்கள் மற்றும் அறிக்கைகள்
- **முறையான மதிப்பாய்வுகள்** — குறிப்பிட்ட தலைப்புகளில் விரிவான ஆதாரத் தொகுப்புகள்

## கல்வியாளர்கள் DevDiscourses-ஐ எவ்வாறு பயன்படுத்தலாம்

### படிப்புப் பட்டியல்களை உருவாக்குதல்

திறந்த-அணுகல் வாசிப்புகளைத் தேட மணிக்கணக்கில் செலவிடுவதற்குப் பதிலாக, உங்கள் பாடநெறி அல்லது பட்டறைக்கான படிப்புப் பட்டியலை உருவாக்க DevDiscourses-ஐ தலைப்பு வாரியாக உலாவுங்கள். ஒவ்வொரு வளமும் தரம் மற்றும் அணுகல்தன்மைக்காகச் சரிபார்க்கப்பட்டுள்ளது.

### இலக்கிய மதிப்பாய்வுகளுக்காக

ஒரு தலைப்பில் ஆதாரத்தை மதிப்பாய்வு செய்ய பங்கேற்பாளர்களுக்குத் தேவைப்படும்போது, DevDiscourses ஒரு தொகுக்கப்பட்ட தொடக்கப் புள்ளியை வழங்குகிறது. கல்விசார் தரவுத்தளங்களில் வழிசெலுத்த வசதியாக இல்லாத செயற்பாட்டாளர்களுக்கு இது குறிப்பாகப் பயனுள்ளது.

### ஒரு குறிப்பு நூலகமாக

DevDiscourses-ஐ ஒரு தொடர்ச்சியான தொழில்முறை வளமாக பங்கேற்பாளர்களுக்கு வழிநடத்துங்கள். அதன் தொகுக்கப்பட்ட தன்மை, அவர்கள் ஆர்வப் பகுதி வாரியாக உலாவவும், கூச்சலை அலசாமல் உயர்தரமான வளங்களைக் கண்டறியவும் உதவுகிறது.

### பாடநெறிகளுடன் சேர்த்து

ImpactMojo-வின் முதன்மைப் பாடநெறிகள் குறிப்பிட்ட கட்டுரைகள் மற்றும் புத்தகங்களைக் குறிப்பிடுகின்றன. DevDiscourses இதை அனைத்து கற்றல் தடங்களிலும் பரந்த, குறுக்குவெட்டுத் தொகுப்புடன் விரிவுபடுத்துகிறது.
