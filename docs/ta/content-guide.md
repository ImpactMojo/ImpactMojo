## Learning Tracks (கற்றல் ட்ராக்குகள்)

உள்ளடக்கம் 6 ட்ராக்குகளாக ஒழுங்கமைக்கப்பட்டுள்ளது:

1. **MEL & Research** — கண்காணிப்பு, மதிப்பீடு, குணரீதியான/அளவுரீதியான முறைகள்
2. **Economics & Policy** — வளர்ச்சிப் பொருளாதாரம், அரசியல் பொருளாதாரம், நிதிதிரட்டல்
3. **Gender & Equity** — பாலின ஆய்வுகள், WEE, பராமரிப்புப் பொருளாதாரம், data feminism
4. **Governance & Society** — அரசியலமைப்பு, காலனித்துவ நீக்கம், சமூக மேம்பாடு
5. **Health & Wellbeing** — பொது சுகாதாரம், காலநிலை, SEL, வாழ்வாதாரங்கள்
6. **Communication & Data** — தரவு எழுத்தறிவு, காட்சி இனவரைவியல், BCC, வாதிடல்

## Flagship Course Structure (Flagship பாடநெறி அமைப்பு)

ஒவ்வொரு flagship பாடநெறியும் ஒரு நிலையான அமைப்பைப் பின்பற்றுகிறது:

- **13 மாட்யூல்கள்** (தோராயமாக)
- 50–65 முக்கியச் சொற்களின் **Lexicon**
- **தென்னாசிய சூழல்** — இந்தியா, பங்களாதேஷ், நேபாளம், இலங்கை ஆகியவற்றிலிருந்து எடுத்துக்காட்டுகள்
- **வழக்காய்வுகள்** — உண்மையான வளர்ச்சித் திட்டங்கள் மற்றும் மதிப்பீடுகள்
- **சிந்தனைத் தூண்டிகள்** — பயிற்சியாளர்கள் தங்கள் பணியுடன் இணைக்க
- **மேலும் படிக்க** — DevDiscourses-லிருந்து தேர்ந்தெடுக்கப்பட்டவை

## Interactive Labs

Labs என்பவை பயிற்சியாளர்கள் கருத்துகளைப் பயன்படுத்த அனுமதிக்கும் HTML/JS பணிமேடைகள். ஒவ்வொரு lab-ம்:

- வழிகாட்டப்பட்ட பணிச்செயல்பாடு (படிப்படியாக) கொண்டது
- ஒரு வெளியீட்டை (கட்டமைப்பு, திட்டம், பகுப்பாய்வு) உருவாக்குகிறது
- முடிவுகளை ஏற்றுமதி செய்யலாம் (premium பதிப்புகளில் PDF/PNG)
- எந்த சர்வரும் தேவையில்லை — முழுவதுமாக உலாவியில் இயங்குகிறது

## Learning Games

விளையாட்டுகள் என்பவை ஒற்றை HTML பக்கங்களாகக் கட்டப்பட்ட பொருளாதார simulation-கள்:

- **தன்னிறைவானவை** — ஒவ்வொரு விளையாட்டும் ஒரு HTML கோப்பு
- **தரவு-இயக்கப்பட்டவை** — முடிந்தவரை உண்மையான பொருளாதார அளவுருக்கள்
- **விவாதிக்கக்கூடியவை** — வகுப்பறை அல்லது பட்டறை பயன்பாட்டிற்காக வடிவமைக்கப்பட்டவை
- **மொபைல்-நட்பு** — பதிலளிக்கக்கூடிய தளவமைப்புகள்

## Adding New Content (புதிய உள்ளடக்கத்தைச் சேர்த்தல்)

### புதிய foundational பாடநெறியைச் சேர்த்தல்

1. இருக்கும் பாடநெறி வடிவத்தைப் பின்பற்றி ஒரு புதிய HTML கோப்பை உருவாக்குங்கள்
2. `catalog.html` இல் உள்ள catalog-க்கு பாடநெறியைச் சேர்க்கவும்
3. `index.html` இல் உள்ள முக்கியத் தளத்தின் பாடநெறிப் பட்டியலில் அதைச் சேர்க்கவும்
4. README உள்ளடக்கப் பட்டியலைப் புதுப்பிக்கவும்

### புதிய விளையாட்டைச் சேர்த்தல்

1. விளையாட்டு தர்க்கத்துடன் ஒற்றை HTML கோப்பை உருவாக்குங்கள்
2. பொருத்தமான கோப்பகத்தில் அல்லது தனி Netlify தளமாக அதை ஹோஸ்ட் செய்யுங்கள்
3. `index.html` மற்றும் `catalog.html` இல் உள்ள விளையாட்டுகள் பிரிவில் அதைச் சேர்க்கவும்

### Handouts சேர்த்தல்

Handouts repo-லிருந்து dynamic ஆக ஏற்றப்படுகின்றன. HTML கோப்புகளை handouts தொகுப்பில் சேர்த்தால் அவை தானாகவே தோன்றும்.

## Style Guide (பாணி வழிகாட்டி)

- **தொனி:** அணுகக்கூடியது ஆனால் கடுமையானது. 2–3 வருட அனுபவம் உள்ள ஒரு பயிற்சியாளருக்காக எழுதுங்கள்.
- **எடுத்துக்காட்டுகள்:** தென்னாசிய சூழலை (இந்தியா, பங்களாதேஷ், நேபாளம், இலங்கை) விரும்புங்கள்.
- **சொற்பயன்பாடு (Jargon):** முதல் பயன்பாட்டில் சொற்களை வரையறுக்கவும். துறை-நிலையான சொற்களானால் ImpactLex-க்குச் சேர்க்கவும்.
- **மேற்கோள் காட்டல்:** ஆதாரங்களை மேற்கோள் காட்டுங்கள். முடிந்தவரை DevDiscourses-க்கு இணைக்கவும்.
- **அணுகல்தன்மை:** semantic HTML, படங்களுக்கு alt உரை, போதுமான வண்ண மாறுபாடு ஆகியவற்றைப் பயன்படுத்துங்கள்.

## How to Write a Deep Dive (Deep Dive-ஐ எப்படி எழுதுவது)

Deep Dives என்பவை தேர்ந்தெடுக்கப்பட்ட விளக்கக்குறிப்பு வாசிப்புப் பட்டியல்கள். ஒவ்வொரு பட்டியலும் ஒரு பெயரிடப்பட்ட curator-இன் குரலைக் கொண்ட ஒரு தலையங்கப் படைப்பு, ஒரு நடுநிலை நூற்பட்டியல் அல்ல — ஒரு தனிநிலை மேற்கோள் பக்கத்தைவிட, பாடத்திட்டமாக-அமையும் நீண்ட-வடிவ கட்டுரைக்கு நெருக்கமானது.

### Deep Dive-இன் அமைப்பு

1. **Hero** — தலைப்பு, ஒரு-வரி tagline, தலைப்பு chip, வாசிப்புகளின் எண்ணிக்கை.
2. **Curator card** — பெயர், பங்கு, 2–3 வாக்கிய சுயவிவரம். `Editor's Pick` (உள்-நிறுவனம்) அல்லது `Invited Curator` எனக் குறிக்கவும்.
3. **Editor's Note** — curator-இன் குரலில் 2–4 பத்தி வடிவமைக்கும் கட்டுரை. இதுவே உள்ளடக்கம்; பட்டியல் என்பது ரசீது.
4. **3–6 கருப்பொருள் பிரிவுகள்** — எ.கா. "Foundations", "Recent Debates", "Voices from the Field". ஒரு தட்டையான பட்டியலை உருவாக்காதீர்கள்.
5. **வாசிப்பு உருப்படிகள்** — ஒவ்வொன்றுக்கும்: ஒரு வகை badge (📘 Book / 📄 Paper / 🎙 Podcast / 🎬 Film / 📊 Dataset / 📰 Article / 🌐 Web), வெளிச்செல்லும் இணைப்புடன் கூடிய முழு மேற்கோள், மற்றும் அந்தப் படைப்பு ஏன் முக்கியம் மற்றும் பாடத்திட்டத்தில் எப்படிப் பொருந்துகிறது என்பதைக் கூறும் 2–4 வாக்கிய விளக்கக்குறிப்பு.
6. **Related ImpactMojo content** — 2–4 பாடநெறிகள், labs, விளையாட்டுகள், அல்லது புத்தகத் துணைகளுக்கு குறுக்கு-இணைப்பு.
7. **Suggested citation** — APA-பாணி மேற்கோள் தொகுதி.
8. **Contribute CTA** — pitch படிவத்திற்கான இணைப்பு.

### உருவாக்க / புதுப்பிக்க வேண்டிய கோப்புகள்

புதிய Deep Dive-ஐச் சேர்க்க:

1. `/DeepDives/_template.html` → `/DeepDives/{slug}.html` நகலெடுக்கவும். தலைப்பு, tagline, தலைப்பு, curator, editor's note, பிரிவுகள், வாசிப்புகளை நிரப்பவும்.
2. `/data/deep-dives.json` இல் ஒரு உள்ளீட்டைச் சேர்க்கவும் (id, title, tagline, topic, url, curator, sections, tags, reading_count, published).
3. `/data/search-index.json` இல் `"type": "deep-dive"` மற்றும் `"category": "Deep Dives"` உடன் ஒரு உள்ளீட்டைச் சேர்க்கவும்.
4. `/sitemap.xml` இல் ஒரு `<url>` உள்ளீட்டைச் சேர்க்கவும்.
5. `catalog.html` `allContent` array-க்கு ஒரு card-ஐச் சேர்க்கவும் (`type: 'deep-dive'`, ஒரு ட்ராக்கைத் தேர்வுசெய்யவும்).
6. (விருப்பம்) flagship-தரமானதாக இருந்தால், `/index.html` இல் உள்ள Deep Dives பிரிவைத் திருத்தி முகப்புப் பக்கத்தில் இடம்பெறச் செய்யவும்.
7. எல்லா இடங்களிலும் எண்ணிக்கை உரையைப் புதுப்பிக்கவும் — `(5 Deep Dives|5 readings)` க்காக grep செய்து எண்ணை உயர்த்தவும்.

### தலையங்க வழிகாட்டுதல்கள்

- **நடுநிலைக்கு மேலாக curator குரல்.** ஒரு பார்வையில்லாத பட்டியல் வெறும் நூற்பட்டியல் மட்டுமே. வாசகரின் கையில் நீங்கள் என்ன திணிப்பீர்கள், ஏன் என்பதைச் சொல்லுங்கள்.
- **கலப்பு ஊடகம் ஊக்குவிக்கப்படுகிறது.** ஒரு நல்ல Deep Dive-இல் கல்விச் சாராம்சத்துடன் குறைந்தது ஒரு podcast, ஒரு dataset, மற்றும் ஒரு பயிற்சியாளர்-மைய ஆதாரம் இருக்கும்.
