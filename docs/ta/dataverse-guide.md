# Dataverse வழிகாட்டி

## Dataverse என்றால் என்ன?

ImpactMojo Dataverse என்பது 16 வகைகளாக ஒழுங்கமைக்கப்பட்ட **343 தரவு மூலங்கள், கருவிகள் மற்றும் சேவைகளின் தேர்ந்தெடுக்கப்பட்ட தொகுப்பு** — குறிப்பாக தென்னாசியா மற்றும் அதற்கு அப்பால் வேலை செய்யும் வளர்ச்சி ஆராய்ச்சியாளர்கள் மற்றும் பயிற்சியாளர்களுக்காக வடிவமைக்கப்பட்டது.

இதை வளர்ச்சி வேலைக்கான உலகின் மிகவும் பயனுள்ள தரவுக்கான வரைபடமாக நினைத்துக்கொள்ளுங்கள், உங்களுக்குத் தேவையானதை நீங்கள் உண்மையில் கண்டுபிடிக்கும் வகையில் ஒழுங்கமைக்கப்பட்டது. சரியான dataset அல்லது கருவியைத் தேடி மணிக்கணக்கில் செலவிடுவதற்குப் பதிலாக, Dataverse சரிபார்க்கப்பட்ட, பொருத்தமான வளங்களை உங்கள் விரல் நுனியில் வைக்கிறது.

Dataverse இல் உள்ள ஒவ்வொரு உள்ளீடும் பொருத்தம், அணுகல்தன்மை மற்றும் தரத்திற்காக மதிப்பாய்வு செய்யப்பட்டுள்ளது. இலவசமாக இருக்கும் அல்லது இலவச அடுக்குகள் கொண்ட, தென்னாசியச் சூழல்களை உள்ளடக்கிய, மற்றும் தரவு விஞ்ஞானிகள் அல்லாதவர்களாலும் பயன்படுத்தக்கூடிய வளங்களுக்கு நாங்கள் முன்னுரிமை அளிக்கிறோம்.

## வள வகைகளைப் புரிந்துகொள்ளுதல்

Dataverse இல் ஏழு வகையான வளங்கள் உள்ளன. இந்தச் சொற்களில் சில உங்களுக்குப் புதியதாக இருந்தால், கவலைப்பட வேண்டாம் — ஒவ்வொன்றும் எதைக் குறிக்கிறது மற்றும் அதை நீங்கள் எப்போது பயன்படுத்துவீர்கள் என்பது இங்கே.

### 1. Dataset

ஒரு **dataset** என்பது தரவின் பதிவிறக்கம் செய்யக்கூடிய தொகுப்பு — எண்கள், கணக்கெடுப்பு பதில்கள், குறிகாட்டிகள், அளவீடுகள் — வரிசைகள் மற்றும் நெடுவரிசைகளில் ஒழுங்கமைக்கப்பட்டது. நீங்கள் எப்போதாவது எண்கள் நிறைந்த ஒரு spreadsheet உடன் வேலை செய்திருந்தால், நீங்கள் ஒரு dataset உடன் வேலை செய்திருக்கிறீர்கள்.

**நீங்கள் இதை எப்போது பயன்படுத்துவீர்கள்:** நீங்கள் ஒரு திட்ட முன்மொழிவை எழுதுகிறீர்கள், மூன்று மாவட்டங்களுக்கான வறுமைப் புள்ளிவிவரங்கள் தேவை. ஒரு திட்டத்திற்கு முன்னும் பின்னும் சுகாதார விளைவுகளை நீங்கள் பகுப்பாய்வு செய்கிறீர்கள். மாநிலங்களில் கல்விக் குறிகாட்டிகளை நீங்கள் ஒப்பிடுகிறீர்கள்.

**எடுத்துக்காட்டு:** இந்தியாவின் தேசிய குடும்ப சுகாதார கணக்கெடுப்பு (NFHS) தரவு — நீங்கள் பதிவிறக்கம் செய்து பகுப்பாய்வு செய்யக்கூடிய சுகாதாரம், ஊட்டச்சத்து மற்றும் மக்கள்தொகை பற்றிய குடும்ப-நிலை தரவு.

### 2. Tool

ஒரு **tool** என்பது நீங்கள் பயன்படுத்தக்கூடிய மென்பொருள் — உங்கள் வலை உலாவியில் அல்லது உங்கள் கணினியில் நிறுவப்பட்டது — தரவுடன் *ஏதாவது செய்ய*. ஒரு chart உருவாக்க. ஒரு கணக்கெடுப்பை உருவாக்க. ஒரு குழப்பமான spreadsheet ஐ சுத்தம் செய்ய. நேர்காணல்களிலிருந்து உரையைப் பகுப்பாய்வு செய்ய.

**நீங்கள் இதை எப்போது பயன்படுத்துவீர்கள்:** ஒரு அறிக்கைக்கு நீங்கள் ஒரு graph செய்ய வேண்டும். ஒரு baseline மதிப்பீட்டிற்கு ஒரு ஆன்லைன் கணக்கெடுப்பை உருவாக்க விரும்புகிறீர்கள். ஒரு PDF அட்டவணையைப் பயன்படுத்தக்கூடிய spreadsheet ஆக மாற்ற முயற்சிக்கிறீர்கள்.

**எடுத்துக்காட்டு:** Datawrapper — எந்த குறியீட்டையும் தெரிந்துகொள்ள வேண்டாம், தெளிவான, தொழில்முறை chart-களை உருவாக்குவதற்கான ஒரு உலாவி-அடிப்படையிலான கருவி.

### 3. Platform

ஒரு **platform** என்பது நீங்கள் தரவு அல்லது வளங்களை ஆராய, தேட மற்றும் பதிவிறக்கம் செய்யக்கூடிய ஒரு வலைத்தளம் அல்லது ஆன்லைன் சேவை. இதை ஒரு நூலகம் போல நினைத்துக்கொள்ளுங்கள், ஆனால் ஆன்லைனில் — உங்களுக்குத் தேவையானதை உலாவவும் கண்டுபிடிக்கவும் நீங்கள் அங்கு செல்கிறீர்கள்.

**நீங்கள் இதை எப்போது பயன்படுத்துவீர்கள்:** ஒரு குறிப்பிட்ட தலைப்பில் தரவைத் தேடுகிறீர்கள் ஆனால் உண்மையில் என்ன கிடைக்கிறது என்று உறுதியாக இல்லை. பாலின சமத்துவத்தை அளவிட என்ன குறிகாட்டிகள் உள்ளன என்பதை ஆராய விரும்புகிறீர்கள். ஒரு குறிப்பிட்ட நாடு அல்லது பகுதியிலிருந்து தரவைக் கண்டுபிடிக்க வேண்டும்.

**எடுத்துக்காட்டு:** World Bank Open Data — உலகின் கிட்டத்தட்ட ஒவ்வொரு நாட்டிற்கும் வளர்ச்சிக் குறிகாட்டிகளை நீங்கள் தேடி பதிவிறக்கம் செய்யக்கூடிய ஒரு platform.

### 4. API (Application Programming Interface)

ஒரு **API** என்பது கணினி நிரல்கள் குறிப்பிட்ட தரவைத் தானாகவே கோர ஒரு வழி. ஒரு வலைத்தளத்திற்குச் சென்று "download" ஐ கிளிக் செய்வதற்குப் பதிலாக, ஒரு API உங்களை "கடந்த 10 ஆண்டுகளுக்கான இந்தியாவின் GDP ஐ எனக்குக் கொடு" என்று சொல்ல அனுமதிக்கிறது — அந்த சேவை சரியாக அந்தத் தரவை திருப்பி அனுப்புகிறது.

**இது உங்கள் வேலைக்கு ஏன் முக்கியம்:** நீங்கள் வழக்கமாகத் தரவை இழுக்க வேண்டியிருந்தால் (மாதாந்திர அறிக்கைகள், காலாண்டு மதிப்பாய்வுகள்), அல்லது பல நாடுகளிலிருந்து ஒரே நேரத்தில் தரவு தேவைப்பட்டால், கைமுறை பதிவிறக்கங்களுடன் ஒப்பிடும்போது ஒரு API மிகப்பெரிய அளவிலான நேரத்தை மிச்சப்படுத்துகிறது.

**பெரும்பாலான API-களைப் பயன்படுத்த நீங்கள் ஒரு புரோகிராமராக இருக்க வேண்டியதில்லை.** பலவற்றில் எளிய வலை இடைமுகங்கள் உள்ளன, அங்கு நீங்கள் விரும்புவதைத் தேர்ந்தெடுத்து முடிவுகளைப் பெறுகிறீர்கள். மேலும் நீங்கள் ImpactMojo இன் தரவுப் பாடநெறிகள் மூலம் வேலை செய்தால், API-களை எப்படிப் படிப்படியாகப் பயன்படுத்துவது என்பதைக் கற்றுக்கொள்வீர்கள்.

**எடுத்துக்காட்டு:** World Bank API குறிப்பிட்ட நாடுகள் மற்றும் ஆண்டுகளுக்கான குறிப்பிட்ட குறிகாட்டிகளைக் கோர உங்களை அனுமதிக்கிறது — உங்களுக்குத் தேவையான தரவு சரியாகத் தேவைப்படும்போது, அதற்கு மேல் எதுவும் வேண்டாம் என்ற நேரத்தில் பயனுள்ளது.

### 5. MCP Server (Model Context Protocol)

ஒரு **MCP Server** என்பது AI உதவியாளர்களை (Claude போன்றவை) நேரடியாக நேரடித் தரவு மூலங்களுடன் இணைக்கும் ஒரு வழி. நீங்கள் கைமுறையாக தரவைக் கண்டுபிடித்து பதிவிறக்கம் செய்வதற்குப் பதிலாக, உங்கள் AI உதவியாளரிடம் "இந்தியாவின் சமீபத்திய GDP தரவை எனக்குக் கொண்டு வா" என்று சொல்லலாம், அது MCP இணைப்பு மூலம் தகவலைப் பெறுகிறது.

**இதை இப்படி நினையுங்கள்:** உங்கள் ஆராய்ச்சி உதவியாளருக்கு ஒரு குறிப்பிட்ட தரவுத்தளத்திற்கான நூலக அட்டை கொடுப்பதாக கற்பனை செய்து பாருங்கள். நீங்கள் நூலகத்திற்குச் செல்லத் தேவையின்றி அவர்கள் இப்போது உங்களுக்காக விஷயங்களைத் தேடலாம். ஒரு MCP Server ஒரு AI உதவியாளருக்கு இதைச் செய்கிறது.

**இது உங்கள் வேலைக்கு ஏன் முக்கியம்:** ஆராய்ச்சியில் AI கருவிகள் மிகவும் பொதுவானதாக மாறும்போது, சிக்கலான தரவு போர்டல்களை வழிசெலுத்துவதற்குப் பதிலாக இயல்பான உரையாடல் மூலம் நம்பகமான, அதிகாரப்பூர்வத் தரவை அணுக MCP Servers உங்களை அனுமதிக்கின்றன. நீங்கள் எளிய மொழியில் ஒரு கேள்வியைக் கேட்கிறீர்கள், AI இணைக்கப்பட்ட மூலத்திலிருந்து துல்லியமான தரவைப் பெறுகிறது.

**எடுத்துக்காட்டு:** இந்தியாவின் data.gov.in உடன் இணைக்கப்பட்ட ஒரு MCP Server சமீபத்திய விவசாய உற்பத்திப் புள்ளிவிவரங்களை ஒரு AI உதவியாளரிடம் கேட்டு உண்மையான தரவைப் பெற உங்களை அனுமதிக்கும் — வெறும் AI இன் பொது அறிவு மட்டுமல்ல.

### 6. Resource

ஒரு **resource** என்பது தரவைப் புரிந்துகொள்ளவும் அதனுடன் வேலை செய்யவும் உதவும் குறிப்புப் பொருள் — முறையியல் வழிகாட்டிகள், கட்டமைப்புகள், கையேடுகள் மற்றும் தேர்ந்தெடுக்கப்பட்ட தொகுப்புகள். இது தரவு அல்ல, ஆனால் தரவு *பற்றிய* அறிவு.

**நீங்கள் இதை எப்போது பயன்படுத்துவீர்கள்:** திட்ட தாக்கத்தை அளவிடுவதற்கான சிறந்த அணுகுமுறையைப் புரிந்துகொள்ள விரும்புகிறீர்கள். நெறிமுறை தரவு சேகரிப்பிற்கான வழிகாட்டி தேவை. உங்கள் மதிப்பீட்டு வடிவமைப்பிற்கான கட்டமைப்பைத் தேடுகிறீர்கள்.

**எடுத்துக்காட்டு:** 3ie Evidence Gap Map முறையியல் வழிகாட்டி — ஒரு வளர்ச்சித் தலைப்பில் என்ன ஆராய்ச்சி உள்ளது (மற்றும் இல்லை) என்பதை முறையாக வரைபடமாக்குவது எப்படி என்பதை விளக்கும் ஒரு resource.

### 7. Skill (Claude Skill)

ஒரு **Skill** என்பது ஒரு குறிப்பிட்ட ஆராய்ச்சி அல்லது பகுப்பாய்வுப் பணியைச் செய்யும் Claude AI உதவியாளருக்கான முன்-கட்டப்பட்ட கட்டளை. ஒரு செய்முறை போல: நீங்கள் skill ஐ அழைக்கிறீர்கள் (ஒரு கட்டளையை தட்டச்சு செய்வதன் மூலம்), மற்றும் ஏதாவது சாதிக்க உங்களுக்கு உதவ அது படிகளின் கட்டமைக்கப்பட்ட வரிசையை இயக்குகிறது.

**நீங்கள் இதை எப்போது பயன்படுத்துவீர்கள்:** ஒரு வளர்ச்சித் திட்டத்தைப் பகுப்பாய்வு செய்ய விரும்புகிறீர்கள் ஆனால் எங்கிருந்து தொடங்குவது என்று உறுதியாக இல்லை. முறையாக இலக்கியத்தை மதிப்பாய்வு செய்ய வேண்டும். ஒரு குறிப்பிட்ட தலையீட்டிற்கான மதிப்பீட்டுக் கேள்விகளை உருவாக்க விரும்புகிறீர்கள்.

**எடுத்துக்காட்டு:** "/analyze-program" போன்ற ஒரு skill ஒரு வளர்ச்சித் தலையீட்டின் கட்டமைக்கப்பட்ட மதிப்பீட்டின் மூலம் உங்களை வழிநடத்தலாம் — உங்களிடம் சரியான கேள்விகளைக் கேட்பது, பொருத்தமான தரவை இழுப்பது, மற்றும் உங்கள் கண்டுபிடிப்புகளை ஒழுங்கமைக்க உதவுவது.

### 1. India Government Data

### 2. Global Development Data

World Bank, ஐக்கிய நாடுகள் நிறுவனங்கள், SDG trackers மற்றும் பன்முக நிறுவனங்களிலிருந்து சர்வதேச வளர்ச்சித் தரவு. நீங்கள் நாடுகளுக்கிடையே ஒப்பிட, உலகளாவிய இலக்குகளைக் கண்காணிக்க, அல்லது சர்வதேச அளவீட்டுக் குறியீடுகளை மேற்கோள் காட்ட வேண்டியிருந்தால் **இங்கிருந்து தொடங்கவும்**.

### 3. Health & Epidemiology

WHO, Demographic and Health Surveys (DHS) திட்டம், நோய் கண்காணிப்பு அமைப்புகள், ஊட்டச்சத்து தரவுத்தளங்கள் மற்றும் சுகாதார வசதி பதிவேடுகளிலிருந்து சுகாதாரத் தரவு. நீங்கள் பொது சுகாதாரம், WASH, ஊட்டச்சத்து அல்லது சுகாதார அமைப்புகளில் வேலை செய்தால் **இங்கிருந்து தொடங்கவும்**.

UNESCO, ASER Centre, கற்றல் விளைவு தரவுத்தளங்கள், பள்ளி உள்கட்டமைப்புத் தரவு மற்றும் எழுத்தறிவு கணக்கெடுப்புகளிலிருந்து கல்வித் தரவு. நீங்கள் கல்வி, திறன் மேம்பாடு அல்லது இளைஞர் திட்டங்களில் வேலை செய்தால் **இங்கிருந்து தொடங்கவும்**.

charts, வரைபடங்கள், டாஷ்போர்டுகள் மற்றும் காட்சிக் கதைகளை உருவாக்குவதற்கான கருவிகள் — Datawrapper, Flourish, chart-உருவாக்க வார்ப்புருக்கள் மற்றும் visualization வழிகாட்டிகள். அறிக்கைகள், விளக்கக்காட்சிகள் அல்லது வெளியீடுகளில் தரவைத் தெளிவாகத் தெரிவிக்க வேண்டியிருந்தால் **இங்கிருந்து தொடங்கவும்**.

2. **வகையின்படி உலாவவும்** — உங்கள் துறையுடன் பொருந்துவதைக் கண்டுபிடிக்கவும்
3. **Platforms மற்றும் Datasets உடன் தொடங்கவும்** — இவை மிகவும் நேரடியான வள வகைகள்
4. **ஒரு கருவியை முயற்சிக்கவும்** — Data Visualization இலிருந்து ஏதாவது தேர்ந்தெடுத்து உங்கள் முதல் chart ஐ உருவாக்கவும்

### Dataverse இலிருந்து அதிகபட்சப் பயன் பெறுவதற்கான குறிப்புகள்

- **நீங்கள் வழக்கமாகப் பயன்படுத்தும் வளங்களை bookmark செய்யுங்கள்.** உங்கள் பிடித்தவற்றைச் சேமிக்க ஒரு இலவச ImpactMojo கணக்கை உருவாக்கவும்.
- **வள வகைகளை இணைக்கவும்.** ஒரு வழக்கமான ஆராய்ச்சிப் பணிப்பாய்வு தரவைக் கண்டுபிடிக்க ஒரு Platform, அதை visualize செய்ய ஒரு Tool, மற்றும் உங்கள் முறையியலை வழிநடத்த ஒரு Resource ஐப் பயன்படுத்தலாம்.
- **தரவின் தேதி மற்றும் கவரேஜைச் சரிபார்க்கவும்.** ஒவ்வொரு dataset ம் ஒவ்வொரு மாநிலத்தையோ ஒவ்வொரு ஆண்டையோ உள்ளடக்காது. உங்கள் பகுப்பாய்வை அதைச் சுற்றி உருவாக்குவதற்கு முன் என்ன சேர்க்கப்பட்டுள்ளது என்பதை எப்போதும் சரிபார்க்கவும்.
- **எளிமையாகத் தொடங்குங்கள்.** நீங்கள் ஒருபோதும் API ஐப் பயன்படுத்தாதிருந்தால், point-and-click இடைமுகம் கொண்ட ஒரு Platform உடன் தொடங்குங்கள். உங்கள் வசதி வளரும்போது API-கள் மற்றும் MCP Servers-க்கு நீங்கள் மேம்படலாம்.
- **உங்கள் குழுவுடன் பகிரவும்.** Dataverse இலவசம் — பயனடையக்கூடிய சகாக்களுடன் குறிப்பிட்ட வள இணைப்புகளைப் பகிரவும்.
