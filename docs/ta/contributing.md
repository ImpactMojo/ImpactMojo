# ImpactMojo இல் பங்களித்தல்

பங்களிக்க ஆர்வம் காட்டியதற்கு நன்றி! ImpactMojo வளர்ச்சிச் சமூகத்தால் மற்றும் அதற்காகவே கட்டப்பட்டது. நீங்கள் காலாவதியான புள்ளிவிவரத்தைக் கண்ட ஒரு பயிற்சியாளராக இருந்தாலும், சிறந்த வழக்காய்வு கொண்ட ஒரு கல்வியாளராக இருந்தாலும், அல்லது ஒரு பிழையைச் சரிசெய்யக்கூடிய ஒரு டெவலப்பராக இருந்தாலும் — உங்களுக்கு பங்களிக்க ஒரு அர்த்தமுள்ள வழி உள்ளது.

## தொழில்நுட்பப் பங்களிப்பாளர்களுக்கு

நீங்கள் HTML, CSS அல்லது JavaScript உடன் வசதியாக இருந்தால், பங்களிக்க ஏராளமான வழிகள் உள்ளன:

| பகுதி | எடுத்துக்காட்டுகள் | கடினம் |
|------|----------|------------|
| **பிழை திருத்தங்கள்** | உடைந்த இணைப்புகள், layout சிக்கல்கள், JavaScript பிழைகள் | எளிது–நடுத்தரம் |
| **அணுகல்தன்மை** | WCAG இணக்கம், screen reader ஆதரவு, keyboard வழிசெலுத்தல் | நடுத்தரம் |
| **வடிவமைப்பு** | UI/UX மேம்பாடுகள், மொபைல் அனுபவம் | நடுத்தரம் |
| **Tools & Labs** | ஊடாடும் கற்றல் கருவிகளை உருவாக்கவும் அல்லது மேம்படுத்தவும் | கடினம் |
| **விளையாட்டுகள்** | புதிய பொருளாதார உருவகப்படுத்துதல்கள் | நடுத்தரம்–கடினம் |

### தொடங்குதல் (தொழில்நுட்பம்)

ImpactMojo ஒரு vanilla HTML/CSS/JS திட்டம் — frameworks இல்லை, build step இல்லை. நீங்கள் வெறும் ஒரு வலை உலாவி மற்றும் ஒரு எளிய சர்வருடன் அதை உள்ளூரில் இயக்கலாம்:

```bash
# 1. Fork and clone the repository
git clone https://github.com/<your-username>/ImpactMojo.git
cd ImpactMojo

# 2. Start a local server (pick whichever you have)
python -m http.server 8000
# or: npx http-server -p 8080

# 3. Open http://localhost:8000 in your browser

# 4. Create a branch for your changes
git checkout -b feature/your-feature-name

# 5. Make your changes, test locally

# 6. Commit using the prefix convention
git commit -m "Add: descriptive summary of what you did"

# 7. Push and open a Pull Request on GitHub
git push origin feature/your-feature-name
```

### Commit செய்தி மரபு

ஒவ்வொரு commit செய்தியும் மாற்றத்தின் வகையை விவரிக்கும் ஒரு முன்னொட்டுடன் தொடங்குகிறது:

| முன்னொட்டு | எப்போது பயன்படுத்த வேண்டும் | எடுத்துக்காட்டு |
|--------|---------------|---------|
| `Add:` | புதிய அம்சம், பாடநெறி அல்லது கருவி | `Add: interactive budget planning lab` |
| `Fix:` | பிழை திருத்தம் அல்லது உடைந்த இணைப்பு | `Fix: broken nav dropdown on mobile Safari` |
| `Update:` | தற்போதுள்ள உள்ளடக்கம் அல்லது குறியீட்டில் மேம்பாடு | `Update: MEL course module 3 with 2025 data` |
| `Translate:` | மொழிபெயர்ப்பு வேலை | `Translate: gender studies course to Hindi` |
| `Docs:` | ஆவண மாற்றங்கள் | `Docs: add workshop facilitation guide` |
| `Refactor:` | குறியீட்டு மறுசீரமைப்பு (நடத்தை மாற்றம் இல்லை) | `Refactor: extract auth logic to separate file` |
| `Test:` | சோதனைகளைச் சேர்த்தல் அல்லது புதுப்பித்தல் | `Test: add accessibility checks for games` |
| `CI:` | CI/CD pipeline மாற்றங்கள் | `CI: add broken link checker workflow` |
| `Chore:` | பராமரிப்பு (dependencies, configs) | `Chore: update dependabot config` |

### Pull Request வழிகாட்டுதல்கள்

- PR-களை கவனம் செலுத்தியதாக வைத்திருங்கள் — ஒரு PR-க்கு ஒரு அம்சம் அல்லது திருத்தம்
- டெஸ்க்டாப் மற்றும் மொபைலில் சோதிக்கவும்
- காட்சி மாற்றங்களுக்கு screenshots சேர்க்கவும்
- மாற்றங்கள் premium அம்சங்களைப் பாதித்தால் குறிப்பிடவும்

## உள்ளடக்க எழுத்துப் பாணி

நீங்கள் கல்வி உள்ளடக்கத்திற்குப் பங்களித்தால், நாங்கள் இலக்காகக் கொண்டது இங்கே:

- **தொனி:** அணுகக்கூடியது ஆனால் கடுமையானது. 2–3 ஆண்டுகள் அனுபவமுள்ள ஒரு பயிற்சியாளருக்காக எழுதுங்கள்.
- **எடுத்துக்காட்டுகள்:** தென்னாசியச் சூழலை விரும்பவும் (இந்தியா, பங்களாதேஷ், நேபாளம், இலங்கை).
- **பரிபாஷை:** முதல் பயன்பாட்டில் சொற்களை வரையறுக்கவும். அது ஒரு பொதுவான துறைச் சொல்லாக இருந்தால், அதை [ImpactLex](https://www.impactmojo.in/impactlex/) இல் சேர்க்கவும்.
- **பங்களிப்பு:** எப்போதும் மூலங்களை மேற்கோள் காட்டவும். முடிந்தவரை [DevDiscourses](https://www.impactmojo.in/dataverse) உடன் இணைக்கவும்.
- **அணுகல்தன்மை:** தெளிவான தலைப்புகள், படங்களுக்கு alt text, மற்றும் போதுமான வண்ண மாறுபாட்டைப் பயன்படுத்தவும்.

## சிக்கல்களைப் புகாரளித்தல்

பொருத்தமான வார்ப்புருவுடன் [GitHub Issues](https://github.com/ImpactMojo/ImpactMojo/issues) ஐப் பயன்படுத்தவும்:

- **Bug Report** — ஏதோ உடைந்துள்ளது (இணைப்பு, layout, பிழை)
- **Feature Request** — ஒரு புதிய யோசனை அல்லது மேம்பாடு
- **Content Issue** — உண்மைப் பிழை, காலாவதியான தகவல், விடுபட்ட தலைப்பு
