# Dataverse গাইড

## Dataverse কী?

ImpactMojo Dataverse হল 16টি বিভাগে সংগঠিত **343টি ডেটা উৎস, টুল এবং পরিষেবার একটি নির্বাচিত সংগ্রহ** — বিশেষভাবে দক্ষিণ এশিয়া এবং তার বাইরে কাজ করা উন্নয়ন গবেষক এবং অনুশীলনকারীদের জন্য ডিজাইন করা।

এটিকে উন্নয়ন কাজের জন্য বিশ্বের সবচেয়ে দরকারি ডেটার একটি মানচিত্র হিসেবে ভাবুন, এমনভাবে সংগঠিত যাতে আপনি আসলে যা প্রয়োজন তা খুঁজে পান। সঠিক dataset বা টুল খুঁজতে ঘণ্টার পর ঘণ্টা ব্যয় করার পরিবর্তে, Dataverse যাচাইকৃত, প্রাসঙ্গিক সম্পদ আপনার নাগালের মধ্যে রাখে।

Dataverse-এর প্রতিটি এন্ট্রি প্রাসঙ্গিকতা, অ্যাক্সেসিবিলিটি এবং গুণমানের জন্য পর্যালোচনা করা হয়েছে। আমরা সেইসব সম্পদকে অগ্রাধিকার দিই যেগুলো বিনামূল্যে বা যাদের বিনামূল্যে স্তর আছে, যেগুলো দক্ষিণ এশীয় প্রেক্ষাপট কভার করে, এবং যেগুলো ডেটা বিজ্ঞানী নন এমন মানুষও ব্যবহার করতে পারেন।

## সম্পদের ধরন বোঝা

Dataverse-এ সাত ধরনের সম্পদ রয়েছে। এই পরিভাষাগুলোর কিছু আপনার কাছে নতুন হলে, চিন্তা করবেন না — প্রতিটি কী বোঝায় এবং কখন আপনি এটি ব্যবহার করবেন তা এখানে।

### 1. Dataset

একটি **dataset** হল ডেটার একটি ডাউনলোডযোগ্য সংগ্রহ — সংখ্যা, জরিপের উত্তর, সূচক, পরিমাপ — সারি এবং কলামে সংগঠিত। আপনি যদি কখনো সংখ্যায় ভরা একটি spreadsheet নিয়ে কাজ করে থাকেন, তাহলে আপনি একটি dataset নিয়ে কাজ করেছেন।

**আপনি কখন এটি ব্যবহার করবেন:** আপনি একটি প্রস্তাব লিখছেন এবং তিনটি জেলার জন্য দারিদ্র্যের পরিসংখ্যান প্রয়োজন। আপনি একটি প্রোগ্রামের আগে এবং পরে স্বাস্থ্যের ফলাফল বিশ্লেষণ করছেন। আপনি রাজ্যগুলোর মধ্যে শিক্ষার সূচক তুলনা করছেন।

**উদাহরণ:** ভারতের জাতীয় পরিবার স্বাস্থ্য জরিপ (NFHS) ডেটা — স্বাস্থ্য, পুষ্টি এবং জনতাত্ত্বিক বিষয়ে পরিবার-স্তরের ডেটা যা আপনি ডাউনলোড এবং বিশ্লেষণ করতে পারেন।

### 2. Tool

একটি **tool** হল এমন সফ্টওয়্যার যা আপনি ব্যবহার করতে পারেন — আপনার ওয়েব ব্রাউজারে বা আপনার কম্পিউটারে ইনস্টল করা — ডেটা দিয়ে *কিছু করতে*। একটি chart তৈরি করুন। একটি জরিপ তৈরি করুন। একটি অগোছালো spreadsheet পরিষ্কার করুন। সাক্ষাৎকার থেকে টেক্সট বিশ্লেষণ করুন।

**আপনি কখন এটি ব্যবহার করবেন:** আপনার একটি রিপোর্টের জন্য একটি graph তৈরি করতে হবে। আপনি একটি baseline মূল্যায়নের জন্য একটি অনলাইন জরিপ তৈরি করতে চান। আপনি একটি PDF টেবিলকে একটি ব্যবহারযোগ্য spreadsheet-এ রূপান্তর করার চেষ্টা করছেন।

**উদাহরণ:** Datawrapper — কোনো কোড জানার প্রয়োজন ছাড়াই স্পষ্ট, পেশাদার chart তৈরির জন্য একটি ব্রাউজার-ভিত্তিক টুল।

### 3. Platform

একটি **platform** হল একটি ওয়েবসাইট বা অনলাইন পরিষেবা যেখানে আপনি ডেটা বা সম্পদ অন্বেষণ, অনুসন্ধান এবং ডাউনলোড করতে পারেন। এটিকে একটি লাইব্রেরির মতো ভাবুন, কিন্তু অনলাইনে — আপনি যা প্রয়োজন তা ব্রাউজ এবং খুঁজতে সেখানে যান।

**আপনি কখন এটি ব্যবহার করবেন:** আপনি একটি নির্দিষ্ট বিষয়ে ডেটা খুঁজছেন কিন্তু আসলে কী উপলব্ধ তা নিশ্চিত নন। আপনি জানতে চান লিঙ্গ সমতা পরিমাপের জন্য কোন সূচকগুলো বিদ্যমান। আপনার একটি নির্দিষ্ট দেশ বা অঞ্চল থেকে ডেটা খুঁজতে হবে।

**উদাহরণ:** World Bank Open Data — একটি platform যেখানে আপনি বিশ্বের প্রায় প্রতিটি দেশের জন্য উন্নয়ন সূচক অনুসন্ধান এবং ডাউনলোড করতে পারেন।

### 4. API (Application Programming Interface)

একটি **API** হল কম্পিউটার প্রোগ্রামগুলোর স্বয়ংক্রিয়ভাবে নির্দিষ্ট ডেটা অনুরোধ করার একটি উপায়। একটি ওয়েবসাইটে গিয়ে "download" ক্লিক করার পরিবর্তে, একটি API আপনাকে বলতে দেয়, "আমাকে গত 10 বছরের জন্য ভারতের GDP দাও" — এবং পরিষেবাটি ঠিক সেই ডেটা ফেরত পাঠায়।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** আপনাকে নিয়মিত ডেটা টানতে হলে (মাসিক রিপোর্ট, ত্রৈমাসিক পর্যালোচনা), বা আপনার একসাথে অনেক দেশ থেকে ডেটা প্রয়োজন হলে, ম্যানুয়াল ডাউনলোডের তুলনায় একটি API প্রচুর পরিমাণে সময় বাঁচায়।

**বেশিরভাগ API ব্যবহার করতে আপনাকে প্রোগ্রামার হতে হবে না।** অনেকগুলোতে সরল ওয়েব ইন্টারফেস আছে যেখানে আপনি যা চান তা নির্বাচন করেন এবং ফলাফল পান। আর আপনি যদি ImpactMojo-এর ডেটা কোর্সের মাধ্যমে কাজ করেন, তাহলে আপনি ধাপে ধাপে API ব্যবহার করতে শিখবেন।

**উদাহরণ:** World Bank API আপনাকে নির্দিষ্ট দেশ এবং বছরের জন্য নির্দিষ্ট সূচক অনুরোধ করতে দেয় — যখন আপনার ঠিক যে ডেটা প্রয়োজন তা দরকার, তার বেশি কিছু নয়, তখন এটি কাজে লাগে।

### 5. MCP Server (Model Context Protocol)

একটি **MCP Server** হল AI সহকারীদের (যেমন Claude) সরাসরি লাইভ ডেটা উৎসের সাথে সংযোগ করার একটি উপায়। আপনি ম্যানুয়ালি ডেটা খুঁজে এবং ডাউনলোড করার পরিবর্তে, আপনি আপনার AI সহকারীকে বলতে পারেন, "আমাকে ভারতের সর্বশেষ GDP ডেটা এনে দাও," এবং এটি MCP সংযোগের মাধ্যমে তথ্য নিয়ে আসে।

**এভাবে ভাবুন:** কল্পনা করুন আপনি আপনার গবেষণা সহকারীকে একটি নির্দিষ্ট ডেটাবেসের লাইব্রেরি কার্ড দিচ্ছেন। আপনার নিজে লাইব্রেরিতে যাওয়ার প্রয়োজন ছাড়াই তারা এখন আপনার জন্য জিনিস খুঁজে দেখতে পারে। একটি MCP Server একটি AI সহকারীর জন্য এটিই করে।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** গবেষণায় AI টুল আরও সাধারণ হয়ে ওঠার সাথে সাথে, MCP Servers আপনাকে জটিল ডেটা পোর্টাল নেভিগেট করার পরিবর্তে স্বাভাবিক কথোপকথনের মাধ্যমে নির্ভরযোগ্য, সরকারি ডেটা অ্যাক্সেস করতে দেয়। আপনি সহজ ভাষায় একটি প্রশ্ন জিজ্ঞাসা করেন, এবং AI সংযুক্ত উৎস থেকে নির্ভুল ডেটা সংগ্রহ করে।

**উদাহরণ:** ভারতের data.gov.in-এর সাথে সংযুক্ত একটি MCP Server আপনাকে একটি AI সহকারীর কাছে সর্বশেষ কৃষি উৎপাদন পরিসংখ্যান চাইতে এবং প্রকৃত ডেটা ফেরত পেতে দিতে পারে — কেবল AI-এর সাধারণ জ্ঞান নয়।

### 6. Resource

একটি **resource** হল রেফারেন্স উপাদান যা আপনাকে ডেটা বুঝতে এবং তা নিয়ে কাজ করতে সাহায্য করে — পদ্ধতিগত গাইড, framework, ম্যানুয়াল এবং নির্বাচিত সংগ্রহ। এটি ডেটা নিজে নয়, বরং ডেটা *সম্পর্কে* জ্ঞান।

**আপনি কখন এটি ব্যবহার করবেন:** আপনি প্রোগ্রামের প্রভাব পরিমাপের সর্বোত্তম পদ্ধতি বুঝতে চান। আপনার নৈতিক ডেটা সংগ্রহের একটি গাইড প্রয়োজন। আপনি আপনার মূল্যায়ন ডিজাইনের জন্য একটি framework খুঁজছেন।

**উদাহরণ:** 3ie Evidence Gap Map পদ্ধতি গাইড — একটি resource যা ব্যাখ্যা করে কীভাবে একটি উন্নয়ন বিষয়ে কোন গবেষণা বিদ্যমান (এবং নেই) তা পদ্ধতিগতভাবে মানচিত্রিত করা যায়।

### 7. Skill (Claude Skill)

একটি **Skill** হল Claude AI সহকারীর জন্য একটি পূর্বনির্মিত কমান্ড যা একটি নির্দিষ্ট গবেষণা বা বিশ্লেষণ কাজ সম্পাদন করে। একটি রেসিপির মতো: আপনি skill আহ্বান করেন (একটি কমান্ড টাইপ করে), এবং কিছু অর্জনে আপনাকে সাহায্য করতে এটি ধাপের একটি কাঠামোবদ্ধ ক্রম চালায়।

**আপনি কখন এটি ব্যবহার করবেন:** আপনি একটি উন্নয়ন প্রোগ্রাম বিশ্লেষণ করতে চান কিন্তু কোথা থেকে শুরু করবেন তা নিশ্চিত নন। আপনাকে পদ্ধতিগতভাবে সাহিত্য পর্যালোচনা করতে হবে। আপনি একটি নির্দিষ্ট হস্তক্ষেপের জন্য মূল্যায়ন প্রশ্ন তৈরি করতে চান।

**উদাহরণ:** "/analyze-program"-এর মতো একটি skill আপনাকে একটি উন্নয়ন হস্তক্ষেপের কাঠামোবদ্ধ মূল্যায়নের মাধ্যমে গাইড করতে পারে — আপনাকে সঠিক প্রশ্ন জিজ্ঞাসা করে, প্রাসঙ্গিক ডেটা টেনে, এবং আপনার ফলাফল সংগঠিত করতে সাহায্য করে।

## 16টি বিভাগ

Dataverse তার 343 সম্পদকে 16টি বিভাগে সংগঠিত করে। প্রতিটিতে কী আছে এবং এটি কার জন্য সবচেয়ে দরকারি তা এখানে।

### 1. India Government Data

ভারতীয় সরকারি সংস্থার সরকারি ডেটা পোর্টাল — data.gov.in, NITI Aayog ড্যাশবোর্ড, আদমশুমারি ডেটা, মন্ত্রণালয়-স্তরের ডেটাবেস এবং রাজ্য ডেটা পোর্টাল। আপনি ভারতে প্রোগ্রামে কাজ করেন এবং সরকারি পরিসংখ্যান প্রয়োজন হলে **এখান থেকে শুরু করুন**।

### 2. Global Development Data

World Bank, জাতিসংঘের সংস্থা, SDG trackers এবং বহুপাক্ষিক সংস্থা থেকে আন্তর্জাতিক উন্নয়ন ডেটা। আপনাকে দেশগুলোর মধ্যে তুলনা করতে, বৈশ্বিক লক্ষ্য ট্র্যাক করতে, বা আন্তর্জাতিক benchmark উদ্ধৃত করতে হলে **এখান থেকে শুরু করুন**।

### 3. Health & Epidemiology

WHO, Demographic and Health Surveys (DHS) প্রোগ্রাম, রোগ নজরদারি ব্যবস্থা, পুষ্টি ডেটাবেস এবং স্বাস্থ্য সুবিধা রেজিস্ট্রি থেকে স্বাস্থ্য ডেটা। আপনি জনস্বাস্থ্য, WASH, পুষ্টি বা স্বাস্থ্য ব্যবস্থায় কাজ করলে **এখান থেকে শুরু করুন**।

### 4. Education & Learning

UNESCO, ASER Centre, শিক্ষণ ফলাফল ডেটাবেস, স্কুল অবকাঠামো ডেটা এবং সাক্ষরতা জরিপ থেকে শিক্ষা ডেটা। আপনি শিক্ষা, দক্ষতা উন্নয়ন বা যুব প্রোগ্রামে কাজ করলে **এখান থেকে শুরু করুন**।

### 5. Economic & Financial

Reserve Bank of India, IMF, বাণিজ্য পরিসংখ্যান ডেটাবেস, আর্থিক অন্তর্ভুক্তি সূচক এবং পরিবার ভোগ জরিপ থেকে অর্থনৈতিক ডেটা। আপনি জীবিকা, বাজার ব্যবস্থা, আর্থিক অন্তর্ভুক্তি বা অর্থনৈতিক নীতিতে কাজ করলে **এখান থেকে শুরু করুন**।

### 6. Research & Evidence

গবেষণা রিপোজিটরি এবং প্রমাণ ডেটাবেস — JSTOR, 3ie evidence gap maps, Cochrane systematic reviews এবং একাডেমিক অনুসন্ধান টুল। আপনি একটি মূল্যায়ন ডিজাইন করছেন, একটি সাহিত্য পর্যালোচনা লিখছেন, বা কী কাজ করে তার প্রমাণ খুঁজছেন হলে **এখান থেকে শুরু করুন**।

### 7. Data Visualization

chart, মানচিত্র, ড্যাশবোর্ড এবং ভিজ্যুয়াল গল্প তৈরির টুল — Datawrapper, Flourish, chart-নির্মাণ template এবং visualization গাইড। রিপোর্ট, উপস্থাপনা বা প্রকাশনায় ডেটা স্পষ্টভাবে যোগাযোগ করতে হলে **এখান থেকে শুরু করুন**।

### 8. M&E & Impact

পর্যবেক্ষণ, মূল্যায়ন এবং শিক্ষণ টুল — MEAL framework, মূল্যায়ন ডেটাবেস, ফলাফল framework template এবং Behaviour Change Technique (BCT) রিপোজিটরি। আপনি একটি M&E ব্যবস্থা স্থাপন করছেন, একটি মূল্যায়ন ডিজাইন করছেন, বা একটি ফলাফল framework তৈরি করছেন হলে **এখান থেকে শুরু করুন**।

### 9. Geospatial & Mapping

GIS টুল, প্রশাসনিক সীমানা ফাইল, স্যাটেলাইট চিত্র সম্পদ এবং মানচিত্রায়ন প্ল্যাটফর্ম। প্রস্তাবের জন্য মানচিত্র প্রয়োজন, একটি প্রোগ্রামের ভৌগোলিক কভারেজ visualize করতে চান, বা অবস্থান-ভিত্তিক ডেটা নিয়ে কাজ করেন হলে **এখান থেকে শুরু করুন**।

### 10. Climate & Environment

IPCC থেকে জলবায়ু ডেটা, গ্রিনহাউস গ্যাস নিঃসরণ trackers, আবহাওয়া API, দুর্যোগ ঝুঁকি ডেটাবেস এবং পরিবেশ নজরদারি টুল। আপনি জলবায়ু অভিযোজন, পরিবেশ প্রোগ্রাম বা দুর্যোগ স্থিতিস্থাপকতায় কাজ করলে **এখান থেকে শুরু করুন**।

### 11. Document & File Processing

ফাইল নিয়ে কাজের ব্যবহারিক টুল — PDF টেক্সট extractors, format converters (PDF থেকে Excel, ছবি থেকে টেক্সট), এবং ডকুমেন্ট parsing utilities। আপনি নিয়মিত PDF, স্ক্যান করা ডকুমেন্ট বা জটিল ফাইল ফরম্যাটে আটকে থাকা ডেটা নিয়ে কাজ করলে **এখান থেকে শুরু করুন**।

### 12. Database & Analytics

বড় পরিসরে ডেটা নিয়ে কাজের টুল — SQL query টুল, পরিসংখ্যানগত computing প্ল্যাটফর্ম, ড্যাশবোর্ড builder এবং ডেটা পরিষ্কারের utilities। আপনি বড় datasets পরিচালনা করেন বা প্রোগ্রাম পর্যবেক্ষণের জন্য ড্যাশবোর্ড তৈরি করতে হলে **এখান থেকে শুরু করুন**।

### 13. Claude Skills & Workflows

উন্নয়ন গবেষণার জন্য ImpactMojo-এর কাস্টম AI কমান্ড — Claude AI সহকারী ব্যবহার করে কাঠামোবদ্ধ গবেষণা কাজ, প্রোগ্রাম বিশ্লেষণ এবং প্রমাণ সংশ্লেষণের মাধ্যমে আপনাকে গাইড করে এমন পূর্বনির্মিত skills। আপনার গবেষণা কাজের জন্য AI টুল ব্যবহার করতে চাইলে **এখান থেকে শুরু করুন**।

### 14. AI Research Tools

গুণগত বিশ্লেষণ, গবেষণা আবিষ্কার, সাহিত্য মানচিত্রায়ন এবং ডেটা অন্বেষণের জন্য AI-চালিত টুল। সাক্ষাৎকার transcript coding, প্রাসঙ্গিক পেপার খোঁজা, বা ডেটায় প্যাটার্ন অন্বেষণের মতো কাজ দ্রুত করতে কৃত্রিম বুদ্ধিমত্তা ব্যবহার করতে চাইলে **এখান থেকে শুরু করুন**।

## Dataverse দিয়ে শুরু করা

### আপনি যদি ডেটা কাজে নতুন হন

একসাথে সবকিছু অন্বেষণ করার চেষ্টা করবেন না। আপনার বর্তমান কাজের সাথে মেলে এমন একটি বা দুটি বিভাগ দিয়ে শুরু করুন, এবং সেখান থেকে সম্প্রসারিত করুন।

1. [impactmojo.in](https://www.impactmojo.in)-এ **Dataverse দেখুন**
2. **বিভাগ অনুযায়ী ব্রাউজ করুন** — আপনার ক্ষেত্রের সাথে মেলে এমনটি খুঁজুন
3. **Platforms এবং Datasets দিয়ে শুরু করুন** — এগুলো সবচেয়ে সরল সম্পদের ধরন
4. **একটি টুল চেষ্টা করুন** — Data Visualization থেকে কিছু বেছে নিন এবং আপনার প্রথম chart তৈরি করুন

### সাধারণ কাজ এবং কোথা থেকে শুরু করবেন

| আপনার প্রয়োজন... | এই বিভাগগুলো দিয়ে শুরু করুন |
|----------------|---------------------------|
| সহায়ক ডেটাসহ একটি প্রস্তাব লেখা | benchmark-এর জন্য **Global Development Data**, স্থানীয় পরিসংখ্যানের জন্য **India Government Data** |
| একটি M&E framework ডিজাইন করা | template এবং framework-এর জন্য **M&E & Impact**, মূল্যায়ন পদ্ধতির জন্য **Research & Evidence** |
| স্পষ্ট ভিজ্যুয়ালসহ একটি রিপোর্ট তৈরি করা | chart টুলের জন্য **Data Visualization**, formatting-এর জন্য **Document & File Processing** |
| একটি হস্তক্ষেপের প্রমাণ পর্যালোচনা করা | systematic reviews এবং প্রমাণ মানচিত্রের জন্য **Research & Evidence** |
| আপনার প্রোগ্রামের কভারেজ এলাকা মানচিত্রিত করা | GIS টুল এবং সীমানা ফাইলের জন্য **Geospatial & Mapping** |
| জরিপ ডেটা বিশ্লেষণ করা | পরিসংখ্যানগত টুলের জন্য **Database & Analytics**, আপনার বিষয় ক্ষেত্রে **Datasets** |
| গবেষণা কাজের জন্য AI ব্যবহার করা | নির্দেশিত কমান্ডের জন্য **Claude Skills & Workflows**, বিশেষায়িত সক্ষমতার জন্য **AI Research Tools** |
| একটি জলবায়ু স্থিতিস্থাপকতা প্রোগ্রাম তৈরি করা | ডেটার জন্য **Climate & Environment**, দুর্বলতা সূচকের জন্য **Global Development Data** |
| PDF রিপোর্ট থেকে ডেটা বের করা | PDF extraction টুলের জন্য **Document & File Processing** |

### Dataverse থেকে সর্বোচ্চ সুবিধা পাওয়ার টিপস

- **আপনি নিয়মিত ব্যবহার করেন এমন সম্পদ bookmark করুন।** আপনার প্রিয়গুলো সংরক্ষণ করতে একটি বিনামূল্যে ImpactMojo অ্যাকাউন্ট তৈরি করুন।
- **সম্পদের ধরন একত্রিত করুন।** একটি সাধারণ গবেষণা workflow ডেটা খুঁজতে একটি Platform, এটি visualize করতে একটি Tool, এবং আপনার পদ্ধতি গাইড করতে একটি Resource ব্যবহার করতে পারে।
- **ডেটার তারিখ এবং কভারেজ পরীক্ষা করুন।** প্রতিটি dataset প্রতিটি রাজ্য বা প্রতিটি বছর কভার করে না। আপনার বিশ্লেষণ এর চারপাশে গড়ার আগে সর্বদা যাচাই করুন কী অন্তর্ভুক্ত।
- **সরল দিয়ে শুরু করুন।** আপনি কখনো API ব্যবহার না করে থাকলে, একটি point-and-click ইন্টারফেস আছে এমন একটি Platform দিয়ে শুরু করুন। আপনার স্বাচ্ছন্দ্য বাড়ার সাথে সাথে API এবং MCP Servers-এ আপনি উন্নীত হতে পারেন।
- **আপনার দলের সাথে শেয়ার করুন।** Dataverse বিনামূল্যে — উপকৃত হতে পারেন এমন সহকর্মীদের সাথে নির্দিষ্ট সম্পদ লিঙ্ক শেয়ার করুন।
