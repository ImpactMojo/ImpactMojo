Free courses in data and code

Code School

Learn the languages and tools of development data work by doing it, running R, Python and SQL in your browser and following guided courses for the desktop software your organisation already uses.

7 in-browser courses10 guided tool coursesFree, with nothing to install

There are two kinds of course here. The courses in the first group run real code in your browser, with R through WebR, Python through Pyodide and SQL through SQLite. The engine downloads once, the first time you press Run, and stays loaded while the page is open. The second group teaches software that cannot run in a browser, such as Stata and QGIS. Those courses set out the commands and the steps and tell you what to look for on your own screen. They do not try to run the software for you.
